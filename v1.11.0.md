# v1.11.0 Split-link recovery, AI app overlays

**Protocol stays at 21.** No firmware update is needed for this app. It works with any firmware from 1.3.1 on, and firmware 1.5.0 can be installed before or after it.

## 1.11.0: When the other half doesn't answer 🔧
- **A firmware or font-pack update that stalls because the second half is silent now says so.** It offers the recovery steps: unplug and replug the cable between the halves, or flash that half's `.uf2` with BOOT held. Before, it said "check the USB cable", which points at the wrong cable.

## 1.10.0: Overlays for AI apps 🤖
- **New keycap overlays for Claude, Claude Code, ChatGPT and Codex**, in the desktop apps and on claude.ai, claude.ai/code and chatgpt.com, each with a macOS set.

## 1.9.2: Leftover pixels around icons
When a recently used keycap slot was reused, parts of the previous icon could stay visible around the new one. Reused slots now get a full redraw.

## 1.9.0: Mock keyboard for development
A firmware emulator behind the mock keyboard, a no-hardware mode, protocol sweeps, fault injection and a board view. These are developer tools only.

## 1.8.0: Overlays that match each platform 🍎
- **macOS sets for Office, Adobe, Teams, Slack, Discord, Zoom, Figma, Obsidian, Krita, DaVinci Resolve, GIMP, Visual Studio, LibreOffice and the web apps.**
- **Windows and Linux cells that contradicted an app's own keymap are fixed**, and overlays match the app names macOS and Windows actually report.

## 1.7.2: Forwarded JetBrains IDEs
A forwarded JetBrains IDE shows its own ESC mark, and a forwarded app's overlay no longer stays on local windows after you switch away.

Plus maintenance releases 1.7.1, 1.8.1, 1.8.2, 1.9.1, 1.9.3, 1.10.1 and 1.10.2 🧹
