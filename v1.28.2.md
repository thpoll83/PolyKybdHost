# v1.28.2 Plugins from Integrations
The protocol stays at 36. Host 1.28.2 works with firmware 1.13.9, and you can update the host and firmware separately.

## 1.28.0: Install every plugin from Integrations 🔌
- **Integrations → Editors now lists every app that needs a plugin:** Blender, Maya, QGIS, Bitwig, VS Code, Cursor, Windsurf, JupyterLab, Godot, Unity and Obsidian. Install, update and remove each one from that page.
- **Godot, Unity and Obsidian install per project or vault.** Pick the folder once, and the app updates the copy when the app updates.
- **A plugin you changed by hand is left alone.** The app does not overwrite or delete it, and the same goes for a VS Code extension of another version.

## 1.28.1: A shorter tray menu ⚙️
- **Keyboard settings move to Settings → Keyboard:** idle display, keycap script and size, tap-hold timing and emoji search. The dialog reads the values from the keyboard and sends only what you change.
- **Tutorials… is now in the top level of the tray menu.** The crash record and the config folder move to Maintenance.
- **Each Settings section has its own colour**, in the sidebar and behind the section.

## 1.27.7, 1.27.10, 1.27.12: Keys that follow FreeCAD, Obsidian and JupyterLab 🧩
- **FreeCAD:** one set per workbench (Sketcher, Assembly, BIM, Draft, TechDraw, Spreadsheet). Esc shows the workbench name.
- **Obsidian:** separate sets for Source, Live Preview, Reading, Canvas and Graph, plus the Vim modes when Vim key bindings are on.
- **JupyterLab:** notebook command and edit mode get their own keys, as do the editor, console and terminal. This needs a Jupyter server on the same computer.

## 1.27.13–1.27.15, 1.27.25: More modes in VS Code, Emacs, Blender and Ableton
- **VS Code, Cursor, Windsurf:** next and previous change in the diff view. The debug state now also works in remote windows (SSH, WSL, containers).
- **Emacs:** sets for the evil states. In Org mode, the evil normal keys are drawn on top of the Org keys.
- **Blender:** new sets for Sequencer, Outliner, Text, Clip, NLA, Curve, Edit Text and Grease Pencil.
- **Ableton Live:** note editor and sample editor sets while the Clip View is expanded (Ctrl+Alt+E).

## 1.27.16, 1.27.20–1.27.24, 1.27.26, 1.27.28, 1.27.29: One icon per action 🎨
Within one app, two different actions no longer share an icon. This covers the game overlays, audio apps, terminals and AI CLIs, design and CAD apps, office and communication apps, ArtCraft, Maya, Vim, Emacs and Blender.

## 1.27.8, 1.27.18, 1.28.2: Agent keys 🤖
- **More computers on one cloud channel:** copy a join code in Connect Cloud Sessions on one computer and use Join with a Code… on the other. Cloud sessions then show on both computers.
- **Cloud sessions are marked** with a small cloud on their key.
- **Larger text on agent cards:** three lines of 14 px. A long title changes page every 3 s.
- **`polyctl agents hooks check`** shows whether the agent hooks reach the host and lists their last runs, from the new `agent_hooks.log`.
- **Anonymous cloud agents:** with `POLYKYBD_CLOUD_ANONYMOUS=1` in the cloud environment, no title or folder name leaves the VM. The keys show "Agent 1", "Agent 2".

## 1.27.19: Emoji search tutorial
Pressing the ringed mode key now ends step 2, and the ring stops.

Plus maintenance releases 1.27.9, 1.27.11 and 1.27.17 🧹
