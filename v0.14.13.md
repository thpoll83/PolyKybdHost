# v0.14.13 Key previews in the layout editor

Pairs with firmware **PolyKybd-fw-v0.17.1**. Protocol is unchanged at **15**, so this
host and your current firmware already talk to each other — update them in either order.

⚠️ **If you are on firmware v0.16.9 or v0.16.10, install v0.17.1 over BOOTSEL + UF2,
not through this app.** That firmware's own update applier has a fault that can leave
the keyboard needing a manual recovery; the host cannot work around it, because the
applier belongs to the firmware already on the board. See the firmware release notes.

## 0.14.11 — The layout editor draws the real keycaps 🔤
Turn on **Key previews** and every key in the editor is rendered the way the keyboard
will actually draw it — the real fonts, the real legends, the real 72×40 panel.
- **It works out of the box.** The preview data now ships with the host (~420 KB), so
  it no longer needs a `qmk_firmware` clone beside the install. Previously the feature
  was only available to firmware developers, and silently *wrong* for anyone whose
  clone had drifted.
- A firmware checkout still wins if it is **strictly newer** than the shipped data, so
  developers preview their own tree. When it loses, the tooltip says so — silence used
  to read as "my clone is being used".
- Emoji and language-layer keys preview too, and a key is resolved by **any** of its
  names rather than the one the browser happened to display.
- Fixes three legends that drew wrongly and one that drew nothing: the Context menu
  key rendered a blank, Scroll Lock lost its lock badge, Pause was unfinished, and two
  keycaps drew a macro's internal *name* as literal text.
- A legend using an op the preview cannot follow is now **refused** rather than
  approximated — a missing preview is honest, a wrong one is not.
- New `tools/preview_doctor.py` answers "why does this look wrong" in one command:
  host and firmware commits, the layer-enum diff, and every layer key's resolved token.

## 0.14.9 — Keys say what they are ⌨️
- **Scroll Lock** and **Pause** are labelled with both of their meanings instead of one.
- An unassigned key reads **NO** rather than looking like a blank waiting to be filled.
- **Hyper** and **Meh** get their real names.
- The keycode composer no longer rewrites a key it was only asked to load.

## 0.14.10 — The firmware-update size limit matches the keyboard again 🛡️
The host's ceiling had drifted from the firmware's staging wall, so it would have
streamed an image the keyboard was always going to refuse. It now checks the real
limit before sending anything.

## 0.14.5 — Pillow security update 🔐
Requires Pillow ≥ 12.3.0 (CVE-2026-54058).
