# v1.20.0 Emulator overlays, keycap face per app
The protocol stays at 27, so this app works with the current firmware 1.10.2. On firmware before 1.10.2 the app still works, but keys switch their keycap face per app only on 1.10.1 or newer, and the new icon library needs 1.10.2.

## 1.19.65: Keycap face per application ⌨️
An overlay entry can now choose the keycap lettering and its placement for as long as that app is in front. The keyboard returns to your own setting when you switch away.

- The VICE emulators show the C64 lettering, and the Amiga emulators show the Amiga lettering, both in the top-left corner of the key.

## 1.19.59 – 1.19.68: Emulator and debugger overlays 🕹️
- **Emulators:** RetroArch, MAME, VICE (the C64 family and the VIC-20), FS-UAE, WinUAE and Amiberry. MAME's Esc key shows a drawn MAME wordmark.
- **GDB:** the terminal title setup now also installs a GDB script, so GDB's keys get one keycap set at the prompt and another while the program runs.

## 1.19.66 – 1.19.69: Sharper icons 🔍
- **Small vector icons are drawn without one-pixel steps and dents** in straight lines.
- **The icon library is rebuilt with 3,527 shared icons** (357 KB). ⚠️ It needs firmware 1.10.2. Older firmware keeps its old library and sends the other icons as images.

Plus maintenance releases 1.19.62, 1.19.63, 1.19.67 and 1.20.0 🧹
