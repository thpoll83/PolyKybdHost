# v1.17.86 Symbols for the emoji picker, three game overlays

## 1.17.83: Symbols and arrows for the emoji picker 🔣
The symbol font pack adds the math symbols and arrows for firmware 1.9.16's Symbols & Math and Marks & Icons tabs. The app flashes it when the keyboard connects.

## 1.17.83 – 1.17.85: New overlays 🎮
- **Minecraft**, Java and Bedrock editions.
- **Warzone 2100.**
- **StarCraft II.** When StarCraft 1 (version 1.16.1) is installed, the control groups, F1 and Backspace keys are drawn from its game files.

## 1.17.86: Fixes 🔧
- **The keyboard no longer leaves Eden by itself.** On KDE Wayland the active window could disappear for a fraction of a second and come back, which woke the keyboard. A lost window now has to stay lost for the same 500 ms delay as a new one.
- **The forwarder has the same Updates submenu as the tray app**, with "Check for host update…" and "Show the running command in the terminal title…".
