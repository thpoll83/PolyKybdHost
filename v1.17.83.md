# v1.17.83 Vim and Emacs modes, game overlays

**Protocol moves to 25.** Update this app first, then the keyboard to firmware 1.9.16. With older firmware the app still connects, but overlay keys keep their legend and the emoji picker has no new symbols.

## 1.17.67 – 1.17.71: Overlays follow Vim, Emacs and nano ⌨️
- **The overlay changes with the editor's mode**, also when the editor runs in a terminal. Vim and Neovim (plugin in `vim-plugin/`) get one overlay per mode. Emacs (package in `emacs-package/`) gets global, Org and Dired sets.
- **GNU nano** gets an overlay too. It is found by the terminal's window title. Updates → *Show the running command in the terminal title…* sets that up for bash, zsh and PowerShell (`polyctl shell-integration install` does the same).

## 1.17.64 – 1.17.83: Symbols and arrows for the emoji picker 🔣
The symbol font pack adds the math symbols and the arrows for firmware 1.9.16's Symbols & Math and Marks & Icons tabs. The app flashes it when the keyboard connects.

## 1.17.52: Overlay keys without the key legend 🎨
An overlay can now replace a key completely, for example a game's ESC mark, instead of drawing beside the legend. Needs firmware 1.9.16.

## 1.17.50 – 1.17.83: New overlays 🎮
- **Games:** Age of Empires II (with a Definitive Edition set) and IV, Command & Conquer Remastered, OpenRA (Red Alert, Tiberian Dawn), Warcraft III, Wargus, RimWorld, Factorio, Minecraft (Java and Bedrock editions), OpenTTD and OpenRCT2.
- **C&C Remastered and OpenRA draw their keys from your own game files** when they are installed.
- **Browser tabs:** Trello, Figma and YouTube.
- **Tools:** Arduino IDE 2, Eclipse, Ghidra, Wireshark, PrusaSlicer, Bambu Studio and OrcaSlicer.
- Existing overlays now include the single-key shortcuts they left out, such as Google Calendar's views.

Plus maintenance releases 1.17.54–1.17.58 and 1.17.61 🧹
