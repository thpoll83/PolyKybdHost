# v1.15.0 Boot-loop test, crash-record readout
**Protocol moves to 22.** This app works with any firmware from 1.3.1 on. The new boot-loop test needs firmware 1.7.0 or later; with older firmware its menu entry stays greyed out. Update the app first, then the firmware.

## 1.15.0: Boot-loop test 🔁
- **Developer → Firmware → "Boot-loop test…" reboots the keyboard up to 9999 times and stops at the first boot that goes wrong.** It reports a crash record, or a reboot that doesn't come back within a minute. Each round takes a few seconds.
- **`polyctl reboot` and `polyctl bootloop [--rounds N] | --cancel`** do the same from the command line.

## 1.14.0: Crash records reach you 🩺
- **The app reads the keyboard's crash record once per keyboard boot and alerts only on a crash it hasn't shown before.** Before, a crash the keyboard recovered from on its own never reached the app.
- **Help & About → "Read keyboard crash record"** reads both halves on demand and copies the result to the clipboard for a bug report.
