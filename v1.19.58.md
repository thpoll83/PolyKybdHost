# v1.19.58 39 new overlays, keycap script placement
The protocol moves from 25 to 27. Update this app first, then the keyboard firmware to 1.10.2. With older firmware the app still works, but the keycap script placement entries stay greyed out and the keyboard keeps its old icon library.

## 1.19.58: Matching icons across apps 🎯
- **One drawing per concept.** Icons that showed the same thing in different apps (save, close, find, arrows) with a few pixels of difference now draw the same, so a switch between apps uploads fewer images.
- **Larger icon library** with 2,520 shared icons, in the 512 KB slot of firmware 1.10.2. ⚠️ After the update the keyboard re-flashes its fantasy, Latin-big and icon font packs once.

## 1.19.52: Keycap script placement 🔤
- **Tray → Keycap Script** has two new entries: *Centred on the keycap* and *In the top-left corner*. Top-left keeps the letter clear of an overlay icon on the right of the key. Needs firmware 1.10.1 or newer (protocol 26).
- `polyctl glyph-script --placement centre|top-left` does the same from the command line.
