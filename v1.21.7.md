# v1.21.7 New settings dialog
The protocol stays at 29, so this app and the keyboard firmware can be updated independently.

## 1.21.7: A new settings dialog ⚙️
- **Settings are grouped into sections** (General, Keycap icons, Brightness, Connections and more), with a list on the left and a search field. Each setting shows its description under its name.
- **The mouse wheel scrolls the page.** A number or a list changes with the wheel only after you click it.
- **New setting Log detail** (Privacy and diagnostics): *Debug* or *Detailed* writes a debug log without starting the app with `--dev`. Applies after a restart.
- **A developer setting that is switched on stays visible** while developer mode is off, so you can turn it off.
- ⚠️ Many settings have new names, for example *Auto Flash* is now *Update on connect*. The values you set are kept.

## 1.21.5: Notes for every release you skip 📜
- **The update dialog shows the notes of every release between your version and the new one**, newest first, for the app and for the keyboard firmware.
