# v1.28.30 MacCompose for macOS, Remote Desktop
The protocol moves from 37 to 38 for MacCompose. This host still works with older firmware, which keeps the old Mac mode. Update this host first, then the firmware to PolyKybd-fw-v1.13.34.

## 1.28.30: Hide agent titles and folders 🕶️
- **Forwarder Settings → AI agents → "Hide agent titles and folders"** stops the agent hooks on that computer from sending titles, folder names and windows. The keys show only the agent's name ("Claude Code 1").
- **Connect Cloud Sessions has the same choice** for cloud sessions: a checkbox shows the `POLYKYBD_CLOUD_ANONYMOUS=1` line to copy into the cloud environment.
- ⚠️ **It applies to agents that start after the change.** Restart a running agent, or it can show twice until its old key is removed.

## 1.28.29: Remote Desktop 🖥️
- **Windows Remote Desktop Connection works like NoMachine**: with the forwarder on the remote computer, the keys show the overlay of the app that is focused there.
- **The forwarder detects the connecting computer for RDP and NoMachine**, with `remote_deploy_scripts.sh` on the remote Linux computer.

## 1.28.23: MacCompose for macOS 🍎
- **Emoji and other Unicode characters type correctly on macOS** with firmware v1.13.34 or newer. The host reads the code the keyboard types while it holds F20 and posts the character. Before, emoji came out as Option characters (∂{¶∂∂€≠≠ on German).
- ⚠️ **PolyKybdHost needs the Accessibility permission** (System Settings → Privacy & Security → Accessibility). Without it, the keyboard stays in the old Mac mode.
- ⚠️ **While an app has Secure Event Input on**, for example a password field, an emoji key types its hex digits instead.

## 1.28.27: Pillow 13
On Python 3.11 and newer, the host now requires Pillow 13.0.0, which fixes the security issues reported against Pillow 12. Python 3.10 stays on Pillow 12.3.0, and the host logs a warning at startup.

## 1.28.24: Integrations in one scrolling column
Integrations now scrolls in one column, like Settings and Help & About. The sidebar jumps to a section and follows the scroll position, and the page fits at 640 px without a sideways scroll bar.
