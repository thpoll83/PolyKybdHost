# v1.17.18 Blender overlays that follow the mode

**Protocol stays at 23.** This app and firmware 1.9.2 can be updated independently.

## 1.17.17: Blender overlays follow the mode 🎨
- **Blender's keycaps follow the current mode and the editor under the mouse**, with 14 shortcut sets (Object, Edit Mesh, Sculpt, Node, UV and more).
- **This needs the PolyKybd Context Reporter add-on** for Blender 4.2 or later, in this repo's `blender-addon/` folder. It sends only the mode and editor name, to this computer only.

## 1.17.14 – 1.17.15: More app overlays 🧩
- **Firefox, Cursor, Windsurf/Devin Desktop and Zed have overlays**, with macOS sets where the shortcuts differ.
- **LM Studio and Jan join the AI chat apps.**
- **The 13 ArtCraft apps have overlays**, from PhotoCraft to GridCraft.

## 1.17.16: Firmware check without a known version 🔧
- **"Check for firmware update…" offers the newest firmware when the keyboard does not report its version.** Before, no dialog appeared.
- **Without a connected keyboard, it says so** instead of waiting.

## 1.17.18: Dialog fixes
Long messages in the update and firmware dialogs are no longer cut off, including the warning about a release that has no firmware file. 12 new interface strings are translated into all 19 languages.
