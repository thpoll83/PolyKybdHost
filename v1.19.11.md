# v1.19.11 AI coding agents in the terminal
The protocol stays at 25. This app and the keyboard firmware can be updated independently. Any firmware since 1.9.15 works with it.

## 1.19.5 – 1.19.11: AI coding agents in the terminal 🤖
- **Claude Code, Codex, OpenCode, Gemini CLI, Qwen Code, GitHub Copilot CLI and Aider** get their own keycap overlays. The app recognises each one by the window title it writes, such as `✳ <topic>` for Claude Code.
- **Codex** does not name itself in its default title. Turn on *Also show Codex in the title* under *Set up the terminal and editors…*, or run `polyctl shell-integration install --codex`. It works in bash, zsh, fish and PowerShell.
- **About 30 more terminals are recognised**, among them Warp, Tabby, Hyper, Wave, Rio, mintty (Git Bash), ConEmu, MobaXterm, Yakuake, Guake, Black Box and COSMIC Terminal.
- **Nushell and xonsh** show the running command without setup, so nano and the AI agents are recognised there too.
- **A program's overlay no longer stays at the prompt after it ends** in bash and zsh, when the prompt sets no title of its own.
- ⚠️ **In tmux**, add `set -g set-titles on` and `set -g set-titles-string '#T'` to `~/.tmux.conf`, or the terminal shows tmux's own title and no overlay loads.

## 1.19.0: Vim, Neovim and Emacs plugins from the tray 🧩
*Set up the terminal and editors…* now lists Vim, Neovim and Emacs, and *Install* copies the mode plugin to where the editor loads it. When the app updates, it copies the new plugin files at its next start.

## 1.18.1 – 1.19.8: New overlays 🎮
- **Apps:** Todoist, Signal Desktop, Telegram Desktop, WPS Office (Writer, Spreadsheets, Presentation) and the Steam client, including Big Picture mode.
- **Browser tabs:** Canva, Google Keep and Photopea.
- **Games:** 0 A.D., DevilutionX, fheroes2 and League of Legends.

## 1.18.5 – 1.18.7: Faster install and update ⚡
- **A fresh install downloads about 13 MB instead of 47 MB.** The installers and the updater leave out the tests and the overlay build inputs, which the app never reads.
- **On Linux, a re-run of `install.sh` skips the package manager** when the hidapi library is already installed.

## 1.18.8 – 1.19.0: Forwarder and Linux fixes
- **A window without a title is forwarded as an empty title, not the text "None"**, so entries with a title rule match it again.
- **Linux: GNOME Terminal gets its ESC icon again, and older PyWinCtl versions report the window's program.**
- **The keyboard console log no longer splits one line into two.**
