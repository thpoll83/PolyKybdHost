# v1.13.0 Web-app title fallbacks, Claude desktop shortcuts

**Protocol stays at 21.** No firmware update is needed for this app. It works with any firmware from 1.3.1 on.

## 1.13.0: Overlays that need no browser extension 🌐
- **Web apps get their overlay from the window title when no URL is known.** This covers GitHub, GitLab, Bitbucket, Confluence, Notion, Google Docs, Claude, Claude Code and ChatGPT. Before, only Miro, Outlook and Jira did this without the extension.
- **Claude desktop draws the Chat-tab shortcuts on both platforms, and the full macOS shortcut list.** On macOS that includes split views, pin, rename, fork, preview and fast mode.
- **Apps that share an action now share its icon.** Swap colours matches GIMP's in Photoshop and Paint.NET, and delete line matches JetBrains' in Notepad++ and Sublime.
- ⚠️ **Title keys of several words now match in your own `overlay-mapping.poly.yaml`**, for example `Claude Code` or `Google Docs`. Before, a key with a space never matched, so a custom mapping that has one may start matching.

## 1.12.0 – 1.12.1: Problem alerts 🩺
- **When the keyboard or the app logs a known error, the app offers a problem report.** You no longer have to dig through log files to find one. Settings can turn this off or include warnings too.
- **A single failed status-display write is a warning, not an error.** The next frame repaints it, so no dialog pops up. Only a burst of failures counts as an error.
