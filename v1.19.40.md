# v1.19.40 18 new overlays, dimmed terminal shortcuts
The protocol stays at 25. This app and the keyboard firmware can be updated independently. Any firmware since 1.9.15 works with it.

## 1.19.39: Terminal shortcuts dimmed under the program 🖥️
While nano, Vim, Emacs or an AI coding agent runs in a terminal, the terminal's own shortcuts stay on the keycaps dimmed, and the program's are drawn at full strength.

- **Windows Terminal** keeps its own set underneath instead of losing it.
- **Every other terminal** shows its harvested shortcuts dimmed. This includes a terminal on a forwarded machine.

## 1.19.12 – 1.19.34: New overlays 🎮
- **Apps:** OBS Studio, SQL Server Management Studio, Clip Studio Paint, Joplin, AutoCAD (Windows and Mac), Everything, PowerToys Command Palette and PowerToys Run, Logseq, ONLYOFFICE Desktop Editors, Total Commander, GitKraken, Sourcetree, CapCut, foobar2000, Winamp and Evernote.
- **Games:** Counter-Strike 2 and Dota 2.

## 1.19.37: Shortcut icons in 19 more languages 🌍
The icons the app finds for an application's shortcuts now also work when its menus are in one of 19 more languages, not only in English.

## 1.19.23 – 1.19.36: Fixes 🔧
- **macOS and Linux: the app comes back after an in-app update** when it was started at login. Before, the new version could be stopped as soon as it started.
- **A firmware download no longer fails on one slow signature read.** The app retries it twice.
- **Settings → Game:** each game folder has a "…" button to choose it, and the log names where the app looked for the game files.
- **Tray, with the background service running:** "Quit" stops both. The quit for the tray alone is now *Only quit GUI*, the last item under Maintenance.

Plus maintenance releases 1.19.22, 1.19.24, 1.19.28, 1.19.38 and 1.19.40 🧹
