# v0.14.1 Macros

## 0.14.0 — Macros ⌨️
Write a macro, give it a caption the keycap spells out, and put it on a key.
- New **Macros** tab in the layout editor's keycode browser — body, caption, keycap
  layout and icon in one place, then assign it like any other keycode.
- A **step editor** for anything beyond plain text: taps, holds, releases, pauses, and
  a recorder that captures a chord as you press it. A **Script** tab shows the same
  macro in VIA-compatible syntax, and `polyctl macro set --script` accepts it.
- The caption meter counts **pixels, not characters**, because the keycap does:
  `WWWWWWWW` fills the display at eight characters while `iiiiiiiiiiii` fits twelve.
- `polyctl macro list|get|set|clear` for the command line.
- **Needs firmware v0.16.10** (protocol v15).
- ⚠️ A macro types **keystrokes** — printable ASCII, tab and newline. Accented letters
  and emoji come from the language and emoji layers instead.

## 0.13.19 — Layer tabs named by the keyboard 🏷️
The editor asks the keyboard what its layers are called (cmd 35, protocol v14) instead
of reading a generated file — which had been stale across two renames and was
mislabelling the tail of every layer list.

## 0.13.17 — Engine-pack size check 🛡️
The host would have streamed ~250 KB of DoomPack over HID for a pack the firmware now
refuses. It checks the real 248 KB limit up front, so an oversized pack costs a
message instead of a full upload.
