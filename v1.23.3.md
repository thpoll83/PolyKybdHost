# v1.23.3 Claude Code cloud sessions
The protocol stays at 34, so this app and the keyboard firmware can be updated in either order. For the Space icons below and for the agent-key ring, update the firmware to 1.13.6 as well.

## 1.23.3: Removing agents and the browser extension 🧩
- **Remove Agent:** AI Agents → Remove Agent frees one agent's key. Remove All Inactive removes every idle, done and stale agent; `polyctl agents forget --inactive` does the same. A removed cloud session is also deleted on the relay.
- **Install Browser Extension…:** copies the PolyKybd browser extension to a folder for "Load unpacked" in Chrome, Edge and other Chromium browsers. After each update of this app, the new version is copied there too.
- **Generate:** a button next to the receiver token in Settings creates a new token and copies it. A new port or token now applies without restarting the app.

## 1.23.2: Space icons
The Space icons in the Pro Tools and Maya overlays are drawn at full size again. This needs firmware 1.13.5 or later; on 1.13.4 they cover part of the ␣.

## 1.23.1: Update dialogs
The update dialogs no longer show an empty band above the message, and short release notes open at their own height.

## 1.23.0: Claude Code cloud sessions ☁️
Sessions on claude.ai/code, also those started from the Claude desktop app, now get agent keys.
- **Connect:** AI Agents → Connect Cloud Sessions… creates a channel on the PolyKybd relay and shows the three values to enter in your claude.ai cloud environment.
- **Privacy:** the relay stores only encrypted reports. The key shows the first words of the session's first prompt; `POLYKYBD_CLOUD_PROMPT_TITLE=0` sends none.
- **Key press:** brings the session's browser tab or the Claude app to the front. With browser extension 1.1.0 it also finds a background tab. When nothing is open, the app asks before it opens the page.
