# v0.11.10 — Anonymous usage reporting (and how to switch it off) 📊

**Please read the first section before updating.** This release starts sending a
small anonymous usage report, and we would rather you learned that here than
discovered it later.

### PolyHost now sends an anonymous daily report

Once a day PolyHost sends us a short report. It exists so we can see which host
and firmware versions people are actually running, and whether updates and
firmware flashes are working — which today we only find out when someone writes
in to say something broke.

**What it contains**

- PolyHost version and protocol version
- Your operating system, its coarse release (e.g. `Windows 11`), CPU
  architecture, Python version
- Your keyboard: model, firmware version, protocol version, hardware revision,
  font-pack versions — and whether one was connected at all
- Counts since the last report: app starts, keyboard connects, connection drops,
  firmware flashes, font-pack flashes, host updates
- A random number generated on your machine, so one install is counted once a day

Our server adds the time it arrived and a two-letter country code taken from the
connection, then discards your IP address.

**What it never contains**

- **Window titles and application names.** PolyHost reads these constantly to
  pick your keycap overlays. They never leave your machine.
- **Anything you type.** No keystrokes, ever.
- **Your location.** The adaptive-brightness feature may look up an approximate
  location for sunrise and sunset; that is never included.
- Your user name, computer name, MAC address, or keyboard serial number.
- File paths, overlay images, or your keymap.

**See it for yourself.** You do not have to take our word for any of the above —
this prints the exact report from your own machine, without sending anything:

```
polyctl telemetry preview
```

**Switching it off** — either of these, at any time:

- **Settings → Telemetry**, untick *Enabled*
- `polyctl telemetry disable`

There is no first-run popup asking you to decide; we would rather tell you here,
before you download, than interrupt you afterwards. It is on unless you turn it
off. Full detail, including how to reset the random ID, is at
[Usage Data & Privacy](https://www.polykybd.org/software/telemetry/).

<sub>A note on the word "anonymous": the report carries nothing that identifies
you, but while only a handful of PolyKybds exist it is not lost in a crowd
either. We would rather say so than imply otherwise.</sub>

### Also

- `polyctl telemetry status | preview | enable | disable | send` for inspecting
  and controlling all of the above from the command line.
