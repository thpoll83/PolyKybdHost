# v1.18.0 Dune, Civilization and KeePass overlays
The protocol stays at 25. This app and the keyboard firmware can be updated independently. Any firmware since 1.9.15 works with it.

## 1.17.91 – 1.18.0: New overlays 🎮
- **Games:** Dune II, Dune 2000 (OpenRA), Freeciv, Freeciv21, and Civilization I, II and IV (Beyond the Sword, Warlords and the base game).
- **Dune II and Dune 2000 draw their keys from your own game files** when they are installed. Settings → Game has a folder and a house for each.
- **The OpenRA Red Alert and Tiberian Dawn overlays** now have each mod's production-tab keys and the power-down key.
- **Tools:** KeePassXC and KeePass 2.x.
- **Browser tabs:** Google Drive.

## 1.17.89 – 1.17.94: Window tracking fixes 🔧
- **KDE Wayland: the keys no longer go blank for a second or two during a game.** If the window can't be read, the keys keep showing the last window.
- **The forwarder no longer wakes the keyboard from Eden** when a window disappears for a fraction of a second. 1.17.86 fixed this on the keyboard's own machine.
- **Linux X11: GNOME Terminal is now recognised**, so the nano and Vim overlays appear in it.

## 1.17.87: Release notes in the update dialog
When GitHub limits the update check, the update dialog now still shows the new release's title, notes and date.

## 1.18.0: Translations
The StarCraft folder and race settings are translated into all 19 languages.
