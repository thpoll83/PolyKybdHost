# v1.22.16 Combos, tap dance and the MIDI guide

The protocol moves from 32 to 34, so update this app first and then the keyboard firmware to 1.13.4. With older firmware this app still connects, but combos, tap dance and the MIDI guide stay off. Firmware 1.13.4 with an app older than this one also leaves them off.

## 1.22.16: Combo editor fixes
A combo or tap dance save that fails part-way now puts the keyboard's previous records back, so a later save cannot store half of it. A tap dance with only a Hold action can be saved. The empty fields say what the keyboard does ("Tap twice"), and keycode names such as `MI_Cs` are matched without regard to case.

## 1.22.15: Overlays for six more music programs 🎹
- **New overlays:** Bitwig Studio, Cubase, Logic Pro, GarageBand, Ardour and LMMS. Each also shows the MIDI guide below.
- **ArtCraft Esc marks:** the apps' Esc marks are now clean silhouettes of their own icons instead of dither.

## 1.22.13: MIDI guide 🎵
The first time a program or web page that takes MIDI input is in front, the keyboard shows how to reach the MIDI layer.
- **The guide:** the focus ripple rings Fn. While Fn is held, it rings the MIDI key, and it stops on the MIDI layer. This needs firmware 1.13.4 (protocol 34).
- **Where it runs:** Ableton Live, REAPER, FL Studio, Pro Tools, MuseScore, SoundCraft and 21 Web MIDI pages. It does not run in Safari, which has no Web MIDI.
- **Once per program:** `polyctl attention --midi --reset` forgets which programs already had it.
- **Browser overlays:** a website without an overlay of its own keeps the browser's overlay at full strength instead of dimmed.

## 1.22.12: Combos and tap dance ⌨️
- **New tabs in the layout editor:** Combos (press 2 to 4 keys together for one keycode) and Tap dance (one key, different actions for tap, hold, double tap and tap-then-hold). There are 16 of each.
- **Storage:** the keyboard stores them in its own flash and copies them to the other half. This needs firmware 1.13.3 or later (protocol 33).
- **Command line:** `polyctl combo` and `polyctl tapdance` list, set and clear them.

## 1.22.11: ArtCraft overlays
Overlays for AniCraft, TextureCraft and MaterialCraft.

## 1.22.10: Layout editor labels
Keycode labels in the browser and on the board always fit their key. The MIDI sharp keys (`MI_Cs` and the others) appear in the browser, and Hyper and Meh keys preview as the keyboard draws them.
