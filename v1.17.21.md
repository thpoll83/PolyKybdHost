# v1.17.21 No more freezes from Windows shortcut reads
**Protocol stays at 23.** This app and firmware 1.9.3 can be updated independently.

## 1.17.21: Shortcut icons without freezes on Windows 🪟
- **Switching browser tabs updates the keycaps right away again.** Reading an app's shortcuts now runs in a separate helper process and stops when you switch away. Before, one long page could freeze the app for over two minutes.
- **Each window title's shortcuts are remembered for 30 minutes**, so going back to a tab needs no new read.
- **Shortcut icons belong to the right app.** The read now checks the window and its process, so Chrome's shortcuts no longer appear under Zoom.
- **Hold the pointer over any setting to see what it does.** The Settings dialog opens at half the screen size. Two settings have clearer names: **Overlays Add Escape Mark** and **Overlays Add Shortcut Icons**.
- **The settings file keeps only the values you changed**, so a better default in a later version reaches you. Your current file is converted once. The glyph-script reset button left Settings; use **Keycap Script → Standard** in the tray menu.

## 1.17.20: Clear Logs
The log viewer has a **Clear Logs…** button that empties every log file, including the crash log. It asks first and offers to collect a log bundle before clearing. Its text is translated into all 19 languages.
