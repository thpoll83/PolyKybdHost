# v1.15.8 C64 keycap script, layout editor on a board photo
**Protocol stays at 22.** This app works with any firmware from 1.3.1 on. The C64 keycap script needs firmware 1.7.11 or later; older firmware shows the normal legends when it is selected.

## 1.15.6: Commodore 64 keycap script 🕹️
- **Keycap Script → "Commodore 64 (keycap)"** draws the letters as the C64 keycaps printed them, with the two PETSCII graphics below each letter.
- **Both Commodore 64 entries now sit together in the menu.** The existing one is renamed "Commodore 64 (screen)".
- The app flashes the updated fantasy font bundle (v7) on the next connect.

## 1.15.4 – 1.15.5: Layout editor on a photo of the board 🖼️
- **The layout editor opens maximized in Real mode, which shows a rendered photo of both halves.** Each key draws its simulated display on its photographed keycap. Symbol and Preview modes are unchanged.

## 1.15.2: Dialog and settings fixes
- **The newer-firmware dialog's buttons work again.** "Check for updates", "Safe mode" and "Connect anyway" all did nothing.
- ⚠️ **Pressing OK in Settings no longer cuts the browser extension's port to 10000.** If the extension stopped reaching the app after you saved settings, set `browser_report_port` back to 50164.
- **The layout editor highlights the active layer button again.**

Plus maintenance releases 1.15.1, 1.15.3, 1.15.7 and 1.15.8 🧹
