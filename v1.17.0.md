# v1.17.0 20 interface languages, dimmed browser icons

**Protocol moves to 23.** This app works with any firmware from 1.3.1 on. Dimmed browser icons need firmware 1.8.3 or later. Update the app first, then the firmware: from firmware 1.8.0, the OS shortcut hints use a font this app flashes.

## 1.17.0: The app speaks your language 🌍
- **Menus and dialogs follow your system language, in 20 languages.** Arabic and Persian are laid out right to left.
- **Settings → Ui → Language picks one yourself.** Logs and `polyctl` stay in English.
- ⚠️ **The translations are machine drafts.** Please report any wording that reads wrong.

## 1.16.6 – 1.16.8: Shortcut icons for Qt and KDE apps on Linux 🐧
- **Qt and KDE apps such as Kate now show shortcut icons on Plasma.** The app turns on the desktop's accessibility bus to read them. Settings → Shortcut → Enable Accessibility turns that off.
- **An app's icons update when its window title changes**, so Kate gains Save, Undo and Copy once a document is open.
- GTK 4.22 and gnome-terminal shortcuts are recognised.

## 1.16.2: Website overlays stand out 🌐
- **On a website, the browser's own icons now draw dimmed under the site's.** This needs firmware 1.8.3 or later; older firmware draws both at full strength.

## 1.16.0 – 1.16.1: Standard shortcuts in every overlay ⌨️
- **27 app overlays now show the standard shortcuts**: copy, paste, undo, save, find and select all.
- **A web app's overlay now layers over its browser's**, so the browser's shortcuts stay visible.
- **OS shortcut hints use one new icon family**, which this app flashes to the keyboard for firmware 1.8.0.
- **The log viewer can search (Ctrl+F)** and colours the keyboard lines the problem scan would report.

Plus maintenance releases 1.16.3–1.16.5, 1.16.7 and 1.16.9–1.16.13 🧹
