## 1.28.18: VS Code extension blocked by a policy 🛡️
- **Editors → Install now says why VS Code refused the PolyKybd extension** when an allowed-extensions rule blocks it. It names the extension ID to ask your administrator for. Before, it showed only "failed". This also applies to Cursor and Windsurf.
