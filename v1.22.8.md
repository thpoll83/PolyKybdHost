# v1.22.8 Agents kept across a restart
The protocol stays at 32, so this app and the keyboard firmware can be updated independently. The keymap note in the firmware update dialog applies to firmware 1.13.1 and later.

## 1.22.8: Keymap changes named before a firmware update
The firmware update dialog now says when an update changes your stored keymap. From firmware 1.13.1: the Hyper key becomes the AI key; keys you remapped and your macros stay.

## 1.22.6: Steadier AI agent keys 🤖
- **Set Up Hooks is always in the AI Agents menu.** The submenu could open empty while it loaded.
- **Agents stay after an app restart:** each agent that reported through a hook comes back with its key, state and title. An agent whose process ended is dropped.
- **The key of an ended session is freed** when pressing it finds no window, instead of staying for up to 4 hours.
- Set Up Hooks and Pair a Forwarder have icons.

## 1.22.5: polyctl --version
`polyctl --version` prints the app version and protocol, even with no app running.
