# v0.10.1 — All nine modifier overlays + WinCompose install

## 0.10.1 — "You're up to date" now tells the truth ✅
The update check reported *"You are running the latest firmware"* even when a newer
firmware release existed but shipped no downloadable file — exactly what happened
with firmware v0.9.82. It now says so plainly and links the release.

### Every modifier combination gets its own keycap art 🎛️
**Ctrl+Alt+Shift** and the **GUI/Win** key now reach the keyboard instead of being
dropped on the way.
- New `*.extra.mods.png` overlay file (Red channel = Ctrl+Alt+Shift). GUI artwork is
  sent from the existing `.combo.mods.` alpha channel, which used to be parsed and
  then thrown away.
- JetBrains ships the first Ctrl+Alt+Shift layer.
- ⚠️ **Pair with firmware 0.9.85+.** The protocol is unchanged at v11 so nothing
  warns you, but the keyboard's overlay storage changed — a mismatched pair puts the
  higher modifier combinations on the wrong keycap image.

## 0.10.0 — Install WinCompose from the tray (Windows) ⌨️
WinCompose is what gives the keyboard full unicode output on Windows, but it's a
separate app a fresh machine won't have. The tray now offers **"Install WinCompose…"**
whenever it isn't running, downloads and launches the installer, and pushes the
improved unicode mode to the keyboard as soon as it comes up — no replug needed.
