# v1.27.29 One icon per action, and keys for more app modes
No firmware change and no protocol change (36). Host 1.27.29 works with the same firmware as 1.27.6. Firmware 1.13.9 has everything this release uses.

## 1.27.16 to 1.27.29: One icon per action 🎨
- **Each action now has its own icon** in the overlays for games, audio apps, terminal programs and AI CLIs, design and CAD apps, office and communication apps, ArtCraft apps, Ableton, Maya, Vim, Emacs and Blender. Before, some different actions shared one image.

## 1.27.7, 1.27.9, 1.27.12: Keys that follow the mode in FreeCAD, Obsidian and JupyterLab 🧩
- **FreeCAD:** the keys follow the active workbench (Sketcher, Part Design, Draft, BIM, TechDraw, Assembly, Spreadsheet). Install the add-on from `freecad-addon/`.
- **Obsidian:** the keys follow the view (Source, Live Preview, Reading, Canvas, Graph) and, with Vim key bindings on, the Vim mode. Install the plugin from `obsidian-plugin/`.
- **JupyterLab 4 and JupyterLab Desktop:** the keys follow the notebook's command or edit mode, the editor, the console and the terminal. Install the extension from `jupyterlab-extension/`.

## 1.27.13 to 1.27.15, 1.27.25: More modes in apps you already use
- **VS Code, Cursor and Windsurf:** the diff view gets its own keys (next and previous change), also while debugging and in remote windows.
- **Emacs with evil:** sets for the normal, visual, insert, replace and motion states.
- **Blender:** sets for the Sequencer, Outliner, Text, Clip, NLA, Curve, Edit Text and Grease Pencil modes.
- **Ableton Live:** the Clip View's MIDI note editor and sample editor get their own sets when the Clip View is shown full size.

## 1.27.8, 1.27.18: Agent keys 🤖
- **Larger text on the agent cards:** three lines of 14 px text around the vendor mark, a state icon in the corner, and a long title shown in pages.
- **Anonymous cloud agents:** with `POLYKYBD_CLOUD_ANONYMOUS=1` in the cloud environment, no title and no folder leave the cloud machine. The keys show these agents as Agent 1, Agent 2.

## 1.27.19: Emoji search tutorial
- **The search mode step ends when you press the mode key.** If the layer was in search mode already, the next step tells you to tap the key once more.
