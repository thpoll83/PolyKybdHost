# v0.10.10 — Every modifier combo & safer defaults

## 0.10.10 — Overlay authoring polish 🎨
- A bare key token in a binding file now resolves as `KC_<TOKEN>`.

## 0.10.9 — Author the new modifier tiers 🎨
- `generate_app_overlays.py` gains the GUI-combo tiers, per-OS selection and a mapping
  reference — so binding files can finally reach the variants the firmware unlocked.

## 0.10.7 — Every modifier combination 🎛️
Host side of the firmware's 16 modifier variants.
- Cmd+Shift, Cmd+Alt and Cmd+Shift+Alt get their own overlays instead of all drawing the
  bare Cmd image.
- The `.extra.mods.png` G/B/A channels are assigned to GUI+Shift / GUI+Alt / GUI+Ctrl.
- ⚠️ **Protocol 12 — update the host app and the firmware together.**

## 0.10.6 — Safer networking by default 🔒
The legacy plaintext window relay (TCP 50162, unauthenticated, all interfaces) is now
**off by default**.
- Use the authenticated path instead: enable `window_report_network_enabled` and run the
  forwarder with `--report-rpc`.
- ⚠️ If you use `--host` forwarding today it will stop until you switch to the
  authenticated path, or opt back in via the `dev_legacy_plaintext_relay` setting. A
  one-time warning points the way.

## 0.10.2 — Firmware signing, host side 🔐
- The host sends the firmware image signature during a flash so the keyboard can verify
  authenticity. Warn-only for now.

Plus maintenance releases 0.10.3–0.10.5 and 0.10.8 🧹
