# v1.28.49 Key lighting settings
The protocol moves to 39. The new key lighting settings need firmware PolyKybd-fw-v1.13.40. With older firmware these rows stay greyed out and everything else works. Update this host first, then the firmware.

## 1.28.49: Key lighting settings 💡
- **Settings → Keyboard → Key lighting**: switch the LEDs under the keys on or off and set their brightness. The Advanced switch shows effect, speed, hue and saturation.
- **Find this keyboard → Blink** blinks the LEDs three times, so you can see which keyboard the dialog changes.
- ⚠️ **The keyboard keeps these changes until it restarts**, then uses its stored settings again.
- `polyctl rgb`, `polyctl uptime` and `polyctl matrix` do the same from the command line. `matrix` shows which keys are down and answers only while the keyboard's debug mode is on.

## 1.28.48: WhatsApp, X and Mastodon overlays 💬
New key overlays for WhatsApp (Windows and Web), X and Mastodon. On X and Mastodon, G shows that it starts a two-key "go to" shortcut.

## 1.28.46: Stuck USB suspend in the crash summary
When the firmware restarts because USB stayed suspended while the PC was awake (firmware 1.13.37), the crash summary now says so in plain words.

## 1.28.43: Windows without a process ID
A window that reports no process ID is now matched to its overlay by the app name.

## 1.28.42: VS Code forks and VM viewers 🧩
- **VS Code Insiders, VSCodium and Code - OSS** get the VS Code overlay. An empty window titled only with the product name now loads it too.
- **VSCodium** can install the editor mode reporter from Integrations → Editors.
- **VirtualBox, VMware, AnyDesk and TeamViewer windows** count as remote viewers: a forwarder inside the guest or on the remote computer drives the overlay.

## 1.28.41: Forwarder on GNOME/Wayland
A reply from the GNOME Window Reporter that is not a JSON object counts as "not available", and the forwarder's window check no longer stops on it.

## 1.28.40: Forwarder resends the window
When the forwarder finds the keyboard computer, it sends the current window at once instead of waiting for the next window change.

## 1.28.39: VS Code from a GNOME/Wayland forwarder
VS Code reported by a GNOME/Wayland forwarder now gets its overlay.

## 1.28.38: GNOME Window Reporter from Integrations 🐧
On GNOME/Wayland, **Integrations → GNOME** installs and turns on the PolyKybd Window Reporter extension, which reports the focused window. Before, this needed a cloned repository and `gsettings` by hand.
