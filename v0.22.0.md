# v0.22.0 A Windows crash fixed, twelve new app overlays & the forwarder's own tray

**No protocol change — still protocol 17**, so this host works with the firmware you
already have. Pairs with **PolyKybd firmware 0.24.4**.

## 0.22.0 — The daemon stops dying on Windows 🪟
- Reading the focused app's name went through **WMI**, walking every running process about
  3.4 times a minute. When a COM connection dropped mid-walk the daemon died **with no log
  line**, taking the keyboard connection with it. It now asks Windows for the one process
  it already has a handle on.
- **Telemetry** adds which window backend is in use, plus the session type and desktop on
  Linux. Both are mapped to a fixed list on your machine, so the raw values never leave it.

## 0.21.0 — Twelve more Windows apps get real keycaps ⌨️
- **Calculator, Sticky Notes, Photos, Sound Recorder, Snipping Tool, Notepad, Paint,
  Paint.NET, WordPad, Task Manager, PuTTY and WinSCP** — hand-made art per shortcut, not
  the generic fallback.
- Sound Recorder also answers to its Windows 10 name, **Voice Recorder**.
- Every overlay is reproducible: a committed script rebuilds the icons from named upstream
  glyphs, with each glyph's source and licence recorded.

## 0.20.0 — The forwarder gets a tray menu worth opening 🔀
- A **status line** that says whether your window reports are actually arriving, and a tray
  icon that greys out when they are not. It used to claim "connected" from startup onwards.
- **Pause**, to stop this machine's window titles leaving it.
- **Help & About** with the log viewer, Report a Problem and Collect logs — for *this*
  machine's logs, which can never appear in a bundle collected on the keyboard side.
- Its tray icon spells an **F** where the keyboard machine's spells a **P**.

## 0.19.6 — Layout editor previews

carried a stale version stamp.
