# v0.22.0 A Windows crash fixed & the forwarder's own tray

Pairs with **PolyKybd firmware 0.24.4** — no protocol change in this release (still protocol 17), so an older keyboard keeps working and you can update the two independently.

## 0.22.0 — The daemon stops dying on Windows 🪟

- **A crash that killed the background daemon twice in one day is gone.** Reading the focused app's name went through **WMI**, which walked *every* running process through COM to answer one question — about 3.4 full process walks a minute. When a COM proxy vanished mid-walk (`RPC_E_DISCONNECTED`) the result was a Windows **access violation**, which is not a Python exception and so could not be caught: the daemon died silently, taking the keyboard connection with it while the keyboard itself kept typing. It now asks Windows for the one process it already has a handle on (`QueryFullProcessImageNameW`) — no COM, no WMI.
- **Telemetry reports which window backend it is using** (payload schema 2). On Linux it also reports the session type (X11/Wayland) and desktop, so "how many installs would this Linux fix reach?" is answerable. The values are mapped to a fixed list **on your machine** — the raw `XDG_*` text never leaves it — and anything unrecognised reports `other`. See [what telemetry sends](https://www.polykybd.org/software/telemetry/).

## 0.21.0 — Twelve more Windows apps get real keycaps ⌨️

Hand-made keycap art per shortcut, not a generic fallback: **Calculator** (69 bindings, read out of Microsoft's own resource files), **Sticky Notes**, **Photos**, **Sound Recorder**, **Snipping Tool**, **Notepad**, **Paint**, **Paint.NET**, **WordPad**, **Task Manager**, **PuTTY** and **WinSCP**.

Every overlay is reproducible — a committed fetch script rebuilds the icons from named upstream glyphs, and each glyph's source and licence is recorded.

## 0.20.0 — The forwarder gets a tray menu worth opening 🔀

If you run PolyKybdHost in forwarder mode on a second computer, its tray menu now has the same shape as the keyboard machine's:

- A **status line** that says whether your window reports are actually arriving — and a tray icon that greys out when they are not. It used to claim "connected" from startup onwards no matter what the network did.
- **Pause**, to stop this machine's window titles leaving it.
- **Settings** and a **Help & About** group, with About, the log viewer, Report a Problem and Collect logs.
- The forwarder's tray icon now spells an **F** where the keyboard machine's spells a **P**, so the two are distinguishable when you forward to your own desktop and both sit in one tray.

## 0.19.6 — The layout editor draws what your keyboard draws 🖼️

Its keycap previews are generated from the firmware, and the shipped copy had fallen behind; it is caught up to firmware 0.23.3. Also fixes the editor clipping the word "Layers:".
