# v1.24.0 Unreal Tournament 2004

The protocol stays at 34, so this app and the keyboard firmware can be updated in either order.

## 1.24.0: Unreal Tournament 2004, and icons that follow your keys 🎮
- **Unreal Tournament 2004:** a new overlay labels 54 keys: the weapons on 1 to 0 and Q, jump, crouch, use, taunts, chat and voice chat, F1 to F12 and the HUD keys.
- **Weapons from your own game:** with UT2004 installed, keys 1 to 0 show the game's own weapon pictures. If the game is not found, set its folder in Settings → Games → Installed games.
- **Icons follow your bindings:** UT2004 icons move to the keys in your User.ini. Warcraft III icons follow the installed language and CustomKeys.txt; a German install shows Move on B and Quit on Alt+B.
- **Warcraft III:** nine more keys: F6 quick save, Alt+G minimap signal, Alt+A ally colours, Alt+F formation, and attack, move, stop, hold position and patrol.

## 1.23.7: Debug keys in VS Code, Cursor and Windsurf 🐞
The new PolyKybd extension for VS Code, Cursor and Windsurf reports when a debug session runs or is paused, and the overlay shows the matching debug keys. Pause is on F6.

## 1.23.6: Maya panels
A Maya plug-in reports the panel under the mouse. The Graph Editor, Time Editor, UV Editor, Node Editor and Hypershade get their own overlays. Not yet tested in Maya.

## 1.23.5: Bitwig Studio Edit view
A Bitwig Studio extension reports the panel layout, and the Edit view gets its own overlay with the Detail Editor keys. Not yet tested in Bitwig Studio.
