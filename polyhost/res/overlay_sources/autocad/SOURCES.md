# Autodesk AutoCAD overlays — sources

One spec (`bindings.yaml`) writes two sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `autocad_template` (2 files, 74 keys) | Windows, `acad.exe` |
| `autocad_template_mac` (4 files, 125 keys) | macOS, "AutoCAD <year>" (the mapping drops the trailing year) |

App names: `acad.exe` is the AutoCAD executable on Windows, and the AutoCAD
for Mac app is named "AutoCAD <year>". Neither name was checked on a running
install. AutoCAD has no Linux version. The AutoCAD-based toolsets (Architecture,
Mechanical, Electrical, ...) also run `acad.exe` and get this set.

## Shortcut reference

The default shortcut keys of the AutoCAD CUIx file, from Autodesk's help,
fetched 2026-11-05:

- Windows: AutoCAD 2026 Customization Guide, "Shortcut Keys Reference",
  <https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-Customization/files/GUID-B6A9C126-230D-47F5-8973-464BC80E3736.htm>.
- macOS: AutoCAD for Mac 2026 Customization Guide, "About Creating and
  Customizing of Shortcut Keys",
  <https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-MAC-Customization/files/GUID-BE1F7F11-E578-4BA2-8AE2-FAA400713FD1.htm>.
  The modifiers in that table are images; the page's legend names them
  (`GUID-688F52FA…` Command, `GUID-1A6EB54E…` Control, `GUID-A5775227…`
  Option, `GUID-7151EC55…` Shift, `GUID-F70DD81D…` Tab).
- macOS function keys: AutoCAD for Mac 2025 Getting Started, "Handy Function
  Key Reference",
  <https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-MAC-GettingStarted/files/GUID-85D8C41C-9C3E-440F-BD60-61848DD27219.htm>
  (F1 to F12, the same as on Windows). On a Mac keyboard they need Fn; on the
  PolyKybd they are plain F-keys.

Command aliases (L for LINE, typed at the command prompt and confirmed with
Enter) are not keyboard shortcuts and are not drawn.

AutoCAD for Mac binds most commands to both Cmd+key and Ctrl+key, and some keys
differ from Windows: Ctrl+E is Toggle Grid (Windows: isoplane), Cmd+3 and Ctrl+9
open the command line, Cmd+1 and Ctrl+3 the tool sets. So the Windows keys and
the Mac keys are separate lists in the spec. The function keys and
Shift+F1..F5 are the same on both.

### Left out

- Windows Ctrl+T: the 2026 page says "Toggles Tablet mode", and the AutoCAD LT
  2015 page of the same reference says tablet mode no longer applies and the
  key creates a new tab. The two disagree, so the key is not drawn.
- macOS Cmd+Left/Right arrow (Show previous/next compare difference): the arrow
  keys are images that the page does not name, and the keys act only in DWG
  Compare.
- macOS Delete (erase): the plain Delete key with no modifier, which the page
  shows only as an image.
- AutoCAD LT (`acadlt.exe`, "AutoCAD LT <year>"): its reference lacks the keys
  marked "AutoCAD only" (Alt+F8, Alt+F11, Ctrl+6, Ctrl+D, Ctrl+I,
  Ctrl+Shift+I, Ctrl+Shift+Y, F6, Shift+F1..F5) and gives F4 another meaning.
- Esc: the ESC key carries the program mark.
