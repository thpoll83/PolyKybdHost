# REAPER overlays — sources

One spec (`bindings.yaml`) writes two sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `reaper_template` (3 files) | Windows (`reaper.exe`) and Linux (`reaper`, WM_CLASS `REAPER`, measured under Xvfb) |
| `reaper_template_mac` (4 files) | macOS (`REAPER.app`, shown as "REAPER") |

## Shortcut reference

REAPER 7.82, the default key bindings of the main section (arrange view),
read 2026-10-21. REAPER has no published default key file; the defaults are
compiled in. They were read two ways:

1. REAPER 7.82 for Linux, run headless with a fresh configuration, listed every
   action with its shortcuts through a startup Lua script (`kbd_enumerateActions`,
   `CountActionShortcuts`, `GetActionShortcutDesc`): 227 keyboard bindings.
2. The default key table compiled into the Linux `reaper`, the Windows
   `reaper.exe` (reaper782_x64-install.exe) and the macOS `REAPER.app`
   (reaper782_x86_64.dmg), decoded and compared. The Linux table matches list 1.

Windows and Linux differ only in the four time-selection edge nudges (Ctrl+, and
Ctrl+. on Windows, the characters < and > on Linux), which are not drawn. macOS
uses Cmd for Ctrl and Option for Alt, as the REAPER User Guide v7.81 (§1.9)
states. The macOS table differs in six bindings, all handled with `only:` /
`except:`: Preferences is Cmd+, (no Cmd+P), Full Screen is Cmd+F11, the Mac
delete key (Backspace) also removes items, Cmd+Backspace cuts the selected
area, and Control+Space is an extra Play/Pause.

Keys REAPER binds as characters (`< > " ~ ! @ ? { } _`) depend on the keyboard
layout; they are drawn on the US key that types them with Shift.

### Left out

- Numpad keys (item move and edge grow/shrink): the keyboard has no numpad.
- Screensets F4..F9 (load) and Shift+F4..F9 (save): a digit drawn over a
  screenset icon does not read at 72x40.
- The time-selection edge nudges (Windows and Linux differ, see above).
- Esc (remove time selection): the ESC key carries the program mark.
- Alt+arrows (scroll view), Up/Down/arrow zoom duplicates (+ = and - also zoom),
  Ctrl+Shift+Up/Down (vertical zoom, also PgUp/PgDn), Ctrl+Alt+Shift+Up/Down,
  Ctrl+Tab (nearest transient; Cmd+Tab is the app switcher on macOS),
  Ctrl+Shift+Tab, Ctrl+Alt+PgUp/PgDn (themes), Ctrl+Alt+Shift+T and Ctrl+Shift+S
  (split ignoring grouping).
- macOS: Cmd+H (Minimize REAPER; the system Hide), Cmd+Space (Spotlight) and
  Insert (no such key on a Mac keyboard).
- Ctrl+Q (Quit), Ctrl+F1 (About), mousewheel and MIDI-CC bindings, and the MIDI
  editor and other sections.

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>. Folder names are in
  `fetch_icons.py`.
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: every `ms:`
  entry in `fetch_icons.py`.
- The numbered icons (go to marker, set marker, go to region) are a digit over
  a square, circle or dotted square, from `../number_badge.py`.
- New, Open, Save, Save As, Undo, Redo, Select All, Copy, Cut, Paste and Delete
  are drawn by the shared concept renderer.
