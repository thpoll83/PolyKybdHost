# Ableton Live overlays — sources

Two specs write four sets, generated by `scripts/generate_app_overlays.py`;
`fetch_icons.py` rebuilds `icons/`.

| Spec | Set | Loads for |
|---|---|---|
| `bindings.yaml` | `ableton_template` (3 files) | Windows: Arrangement View, and no report |
| `bindings.yaml` | `ableton_template_mac` (4 files) | macOS: the same |
| `session.yaml` | `ableton_session_template` (3 files) | Windows: Session View |
| `session.yaml` | `ableton_session_template_mac` (4 files) | macOS: Session View |

The view comes from the PolyKybd remote script (`ableton-remote-script/`),
which reports `ableton://session` or `ableton://arrangement`. Without the
script, or with a report older than 8 s, the Arrangement set is shown.

App names: the Windows executable and the macOS app are both named after the
edition, "Ableton Live 12 Suite" (`Ableton Live 12 Suite.exe`, confirmed from an
Ableton forum post), Standard, Intro, Lite and Trial (by the same pattern, not
checked). Live has no Linux version. Live 11 and older are not mapped.

## Shortcut reference

Ableton Reference Manual Version 12, chapter "Live Keyboard Shortcuts",
<https://www.ableton.com/en/manual/live-keyboard-shortcuts/>, fetched
2026-10-21. It gives the Windows and the Mac key side by side. The Mac keys
that are not the Cmd/Option version: Redo (Cmd+Shift+Z), Full Screen
(Ctrl+Cmd+F), Stop at End of Selection (Option+Space).

Session View and Arrangement View are one OS window, so the window tracker
cannot tell them apart; the remote script tells the host. `bindings.yaml` has
the global keys and the Arrangement View keys (section 42.16). `session.yaml`
has the same global keys, without the Arrangement View section and without U
and Alt+U, plus the Session View keys of section 42.15: Enter (launch),
Shift+Enter (follow actions on/off), Ctrl+Enter (stop clips in track),
Ctrl+Shift+Enter (follow action chain), Ctrl+E (stop button), Ctrl+I (insert
scene), Ctrl+Shift+I (insert captured scene), Ctrl+Shift+M (insert MIDI clip).

The detail view (Clip or Device) is reported but has no set of its own. Its
keys (section 42.12, for example Ctrl+J Join Notes and Ctrl+E Chop Notes) apply
only while the detail view has the keyboard focus, and the Live API reports
which detail view is open, not which part of the window has the focus.

The Computer MIDI Keyboard (M, off by default per Ableton's help article
"Computer MIDI Keyboard off by default") makes the home row and upper row play
notes, Z/X change the octave and C/V the velocity. While it is on, Live 12
reaches the single-letter shortcuts with Shift (Shift+S solos).

### Left out

- Keys whose meaning depends on the view are drawn with their Arrangement
  meaning: Ctrl+E is Split Clip (in Session it adds or removes a stop button),
  Ctrl+I is Insert Silence (in Session it inserts a scene). The Arrangement set
  leaves the Session-only keys out: Ctrl+Shift+M (Insert MIDI clip), Enter, the
  arrows and PgUp/PgDn. The Session set has the first two, and Ctrl+E and Ctrl+I
  with their Session meaning.
- Follow Playback: the manual gives Alt+Shift+F in one section and Ctrl+Shift+F
  in three others, and Ctrl+Shift+F is also MIDI Note Filters and Similarity
  Search.
- Ctrl+Alt+V (Video Window and Paste Bounced Audio), the Clip View editor keys
  (Ctrl+Tab, Alt+Shift+1..3, Ctrl+J Join Notes, K Highlight Scale), the focus keys
  (Alt+0..8), F and E (held, momentary), the zoom keys (Ctrl++, Ctrl+-, + and -,
  which need Shift for + on a US layout).
- Mouse modifiers (Alt+drag, Ctrl+click and so on), and Cmd+H (Hide) on macOS.
- Esc: the ESC key carries the program mark, which the host draws.

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>. Folder names are in
  `fetch_icons.py`.
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: every `ms:`
  entry in `fetch_icons.py`.
- `track1..track8.png`: Fluent `Square` with a digit, from `../number_badge.py`.
- Session View icons (`launch`, `followact`, `stopclips`, `followchain`,
  `stopbutton`, `insertscene`, `capturescene`, `midiclip`): Material Symbols,
  names in `fetch_icons.py`.
- New, Open, Save, Save As, Undo, Redo, Cut, Copy, Paste, Select All and Delete
  are drawn by the shared concept renderer.
