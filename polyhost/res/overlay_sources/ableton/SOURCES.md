# Ableton Live overlays — sources

Four specs write eight sets, generated by `scripts/generate_app_overlays.py`;
`fetch_icons.py` rebuilds `icons/`.

| Spec | Set | Loads for |
|---|---|---|
| `bindings.yaml` | `ableton_template` (3 files) | Windows: Arrangement View, and no report |
| `bindings.yaml` | `ableton_template_mac` (4 files) | macOS: the same |
| `session.yaml` | `ableton_session_template` (3 files) | Windows: Session View |
| `session.yaml` | `ableton_session_template_mac` (4 files) | macOS: Session View |
| `clip_midi.yaml` | `ableton_clipmidi_template` (3 files) | Windows: expanded Clip View, MIDI clip |
| `clip_midi.yaml` | `ableton_clipmidi_template_mac` (4 files) | macOS: the same |
| `clip_audio.yaml` | `ableton_clipaudio_template` (3 files) | Windows: expanded Clip View, audio clip |
| `clip_audio.yaml` | `ableton_clipaudio_template_mac` (4 files) | macOS: the same |

The view comes from the PolyKybd remote script (`ableton-remote-script/`),
which reports `ableton://session` or `ableton://arrangement`, plus
`/clip/midi`, `/clip/audio` or `/device` for the detail view and `/full` when
the Clip View fills the window. Without the script, or with a report older
than 8 s, the Arrangement set is shown.

App names: the Windows executable and the macOS app are both named after the
edition, "Ableton Live 12 Suite" (`Ableton Live 12 Suite.exe`, confirmed from an
Ableton forum post), Standard, Intro, Lite and Trial (by the same pattern, not
checked). Live has no Linux version. Live 11 and older are not mapped.

## Shortcut reference

Ableton Reference Manual Version 12, chapter "Live Keyboard Shortcuts",
<https://www.ableton.com/en/manual/live-keyboard-shortcuts/>, fetched
2026-10-21. It gives the Windows and the Mac key side by side. The Mac keys
that are not the Cmd/Option version: Redo (Cmd+Shift+Z), Full Screen
(Ctrl+Cmd+F), Stop at End of Selection (Option+Space).

Session View and Arrangement View are one OS window, so the window tracker
cannot tell them apart; the remote script tells the host. `bindings.yaml` has
the global keys and the Arrangement View keys (section 42.16). `session.yaml`
has the same global keys, without the Arrangement View section and without U
and Alt+U, plus the Session View keys of section 42.15: Enter (launch),
Shift+Enter (follow actions on/off), Ctrl+Enter (stop clips in track),
Ctrl+Shift+Enter (follow action chain), Ctrl+E (stop button), Ctrl+I (insert
scene), Ctrl+Shift+I (insert captured scene), Ctrl+Shift+M (insert MIDI clip).

### Clip View sets

`clip_midi.yaml` has the global keys of `session.yaml` (its sections before
"Session View") and the MIDI Note Editor keys: section 42.12 (Ctrl+E Chop
Notes, Ctrl+Shift+E Split Clip, Ctrl+J Join Notes, Ctrl+Alt+J Fit Notes to
Time Range, Ctrl+Shift+A Invert Note Selection, Ctrl+Enter Apply MIDI Tool,
Ctrl+Shift+F MIDI Note Filters, Ctrl+Alt+E Expand Clip View, Ctrl+G and
Ctrl+Shift+G Group and Ungroup Notes, K Highlight Scale, Home and End, PgUp and
PgDn, Shift+PgUp and Shift+PgDn, Alt+arrows Select Note, Ctrl+Up/Down
Velocity, Ctrl+Shift+Up/Down Velocity Deviation, Ctrl+Alt+Up/Down Chance, Z,
X, H, W), section 42.10 (Ctrl+Tab, on macOS Option+Tab, and Alt+Shift+1..3 for
the editor tabs), and chapter 10 "Editing MIDI"
(<https://www.ableton.com/en/manual/editing-midi/>, fetched 2026-11-15): F Fold
to Notes, G Fold to Scale, N Focus Mode, 0 Deactivate Notes. C (Arm) and S
(Solo) are left out: the manual does not say they act while the note editor
has the focus.

`clip_audio.yaml` has the same global keys and the Sample Editor keys of
section 42.11: Left/Right Move Warp Marker, Ctrl+Left/Right Select Warp
Marker, Shift+Left/Right Move Clip Region, Ctrl+I Insert Warp Marker, Delete
Delete Warp Marker, Ctrl+Shift+I Insert Transient, Ctrl+Shift+Delete Delete
Transient, Z, X, H, W, and the editor tab keys of 42.10. Ctrl+G, Ctrl+Shift+G
(42.4: they group devices when the Device View has the focus), C, S and 0 are
left out.

Left out of both: Ctrl+PgUp/PgDn (scroll horizontally; the manual does not
say which key scrolls which way), Shift+Left/Right in the note editor (42.12
says Move Clip Region, chapter 10 says extend the time selection or the
notes), the mouse modifiers and the held keys (E, Ctrl+E drag).

⚠️ Chapter 10 gives other Windows keys than 42.12 for some note-editor
arrows: Ctrl+Up/Down to select a note (42.12: Alt+Up/Down; Ctrl+Up/Down is
velocity) and Ctrl+Shift+Up/Down to add notes to the selection (42.12:
velocity deviation). The sets follow 42.12. The Mac keys agree (Option).

The host routes these sets only for `/clip/midi/full` and `/clip/audio/full`.
The Live API reports which detail view is shown, not which part of the window
has the keyboard focus, and the Clip View "always shows the currently selected
clip" (manual, chapter "Clip View"), so it is on screen while the main-view
keys act on that clip. With the main view visible the main view's set stays;
see `ableton-remote-script/README.md`.

The Computer MIDI Keyboard (M, off by default per Ableton's help article
"Computer MIDI Keyboard off by default") makes the home row and upper row play
notes, Z/X change the octave and C/V the velocity. While it is on, Live 12
reaches the single-letter shortcuts with Shift (Shift+S solos).

### Left out

- Keys whose meaning depends on the view are drawn with their Arrangement
  meaning: Ctrl+E is Split Clip (in Session it adds or removes a stop button),
  Ctrl+I is Insert Silence (in Session it inserts a scene). The Arrangement set
  leaves the Session-only keys out: Ctrl+Shift+M (Insert MIDI clip), Enter, the
  arrows and PgUp/PgDn. The Session set has the first two, and Ctrl+E and Ctrl+I
  with their Session meaning.
- Follow Playback: the manual gives Alt+Shift+F in one section and Ctrl+Shift+F
  in three others, and Ctrl+Shift+F is also MIDI Note Filters and Similarity
  Search.
- Ctrl+Alt+V (Video Window and Paste Bounced Audio), the Clip View editor keys
  in these two sets (they are in `clip_midi.yaml` and `clip_audio.yaml`), the focus keys
  (Alt+0..8), F and E (held, momentary), the zoom keys (Ctrl++, Ctrl+-, + and -,
  which need Shift for + on a US layout).
- Mouse modifiers (Alt+drag, Ctrl+click and so on), and Cmd+H (Hide) on macOS.
- Esc: the ESC key carries the program mark, which the host draws.

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>. Folder names are in
  `fetch_icons.py`.
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: every `ms:`
  entry in `fetch_icons.py`.
- `track1..track8.png`: Fluent `Square` with a digit, from `../number_badge.py`.
- Session View icons (`launch`, `followact`, `stopclips`, `followchain`,
  `stopbutton`, `insertscene`, `capturescene`, `midiclip`): Material Symbols,
  names in `fetch_icons.py`.
- Clip View icons (`chopnotes`, `joinnotes`, `fittime`, `groupnotes`,
  `ungroupnotes`, `applytool`, `invertsel`, `highlightscale`, `foldnotes`,
  `foldscale`, `focusmode`, `notefilters`, `expandclip`, `cliphome`,
  `clipend`, `nexttab`): Material Symbols, names in `fetch_icons.py`.
- Clip View composites (`oct_*`, `row_*`, `note_*`, `vel_*`, `dev_*`,
  `prob_*`, `tab_*`, `warp_*`, `warpsel_*`, `region_*`, `trans_*`): drawn 1-bit
  at 40x40 by `../ghidra/fetch_icons.py` `composites()`, an arrow, a `+` or
  `−`, or the `nexttab` glyph over a word in Liberation Sans Bold (SIL OFL 1.1).
  The list is `COMPOSITES` in `fetch_icons.py`.
- New, Open, Save, Save As, Undo, Redo, Cut, Copy, Paste, Select All and Delete
  are drawn by the shared concept renderer. In `clip_audio.yaml` Delete deletes
  the warp marker and has its own icon.
- One icon per action: the 0 key is "Deactivate" in every set. The manual
  names it Deactivate Selection (42.16), Deactivate Selected Clip (42.15),
  Deactivate Selected Track (42.19) and Deactivate Notes (10.5.7): one Edit
  menu command applied to the selection.
