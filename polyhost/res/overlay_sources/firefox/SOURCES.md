# Mozilla Firefox overlay: sources

Generated by `scripts/generate_app_overlays.py` from `bindings.yaml`; icons
rebuilt by `fetch_icons.py`. One spec, three artwork sets: `firefox_template.*`
(Windows), `firefox_template_linux.*` (Linux: tab select on Alt, Downloads on
Ctrl+Shift+Y, web search on Ctrl+J, ...) and `firefox_template_mac.*`
(`CMDCTRL` resolved to Cmd, plus the macOS-only rows).

## Shortcuts: authority

Firefox's own key definitions, at the **release** branch (Firefox 158.0.1),
`mozilla-firefox/firefox` commit `1a0cfe22a2d8ba77e77cc8f43eaa480e34eca181`
(read 2026-10-13). `main` (Nightly, `d8b0cd3f8ed35b6c7094e274d180ed3ef5e7e637`)
differs in two rows that have NOT shipped: Ctrl+Shift+A becomes "Search tabs" and
Add-ons moves to Ctrl+Shift+F / ⌘⇧E. Re-check this file against `release` when
that reaches a release. ESR 140 lacks the Ctrl+Alt+U "Open tabs sidebar" key.

- `browser/base/content/browser-sets.inc.xhtml` (`<keyset id="mainKeyset">`) with
  the letters in `browser/locales/en-US/browser/browserSets.ftl`.
  `accel` = Ctrl on Windows/Linux, Cmd on macOS -> `CMDCTRL`; `control` = literal
  Ctrl everywhere -> `CTRL`. `XP_UNIX` is Linux **and** macOS; `XP_GNOME` is every
  Linux (GTK) build.
- `devtools/startup/DevToolsStartup.sys.mjs` (KeyShortcuts) +
  `devtools/startup/locales/en-US/key-shortcuts.ftl`.
- `toolkit/modules/ShortcutUtils.sys.mjs` `getSystemActionForEvent` (tab cycling,
  Ctrl+F4, F7), dispatched by `Tabbrowser.sys.mjs` `on_keydown`.

The Mozilla Support page "Keyboard shortcuts - Perform common Firefox tasks
quickly" (support.mozilla.org/kb/keyboard-shortcuts-perform-firefox-tasks-quickly)
was the cross-check, but it did not render for the fetcher (script-only page), so
the source above is the sole authority used.

### Where Firefox differs from Chrome

Private window is Ctrl+Shift+**P** (Chrome: Shift+N; here Shift+N reopens a closed
window). Library is Ctrl+Shift+O (bookmarks) / Ctrl+Shift+H (history); Ctrl+H is the
history SIDEBAR. Downloads is Ctrl+Shift+Y on Linux. Tab select is Alt+1..9 on
Linux. Ctrl+K / Ctrl+E (Ctrl+J Linux) focus web search. Ctrl+M mutes the tab. Ctrl+B
toggles the bookmarks sidebar. Add-ons Ctrl+Shift+A. Ctrl+Shift+Delete clears history.
Reader view F9 / Ctrl+Alt+R and Picture-in-Picture Ctrl+Shift+] have no Chrome
equivalent. DevTools use Ctrl+Shift+<panel letter> (Chrome: only I/J/C).

### Decisions on shared chords

- **Ctrl+Shift+Z on Linux** is both Redo (`key_redo`, text fields) and the DevTools
  Debugger (global). The global action, Debugger, is drawn; Linux Redo is not.
  Windows Redo is Ctrl+Y; macOS Redo is ⌘⇧Z (macOS Debugger is ⌘⌥Z).
- **Ctrl+Shift+W** is also the DevTools DOM panel key, but `key_closeWindow` is
  `reserved="true"`, so Close window wins and the DOM panel is not drawn.

### Skipped

- Escape (`key_stop`) and Shift+Esc (Process Manager): Escape is the program-mark cell.
- F6 (cycle focus to the address bar): not in any keyset read here (focus navigation).
- Address-bar-only completions Ctrl/Shift/Alt+Enter, and Shift+Backspace (pref-gated
  `cmd_handleShiftBackspace`, default off): context-only, not global.
- Delete (`key_delete`) and Backspace without modifiers: plain editing keys.
- Tab-strip-focused keys (accel+arrows, accel+Shift+Home/End move tab): only when the
  tab strip has focus.
- Profiler Ctrl+Shift+1/2 (only when the profiler button is in the toolbar), JS
  tracer Ctrl+Shift+5 (pref-gated), Nightly-only window recording.

Labels that name a lexicon concept (Save, Open, Print, Cut, Copy, Paste, Undo, Redo,
Select all, Settings, Minimize) are drawn by the shared concept renderer, so those
cells are byte-identical to every other app's; their files in `icons/` (if any)
are unused. "Reload (skip cache)" sets `shared: false` because it folds onto the
Reload concept and must stay distinct from plain Reload.

## ESC program mark

None baked (no `program_icon:`), exactly like `chrome_template`. The Firefox logo is
a Mozilla trademark ("Firefox and the Firefox logos are trademarks of the Mozilla
Foundation", `browser/branding/official/locales/en-US/brand.ftl`) and the official
branding is outside the MPL grant, so it is not redistributed here. The generic
program mark resolves it at runtime: the running Firefox's own OS icon first, else
Simple Icons `firefox` (CC0-1.0, present in the pinned 15.22.0), else `mdi:firefox`.
