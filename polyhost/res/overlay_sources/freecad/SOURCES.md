# FreeCAD overlays — sources

One spec (`bindings.yaml`) writes three sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `freecad_template` (2 files) | Windows, `FreeCAD.exe` |
| `freecad_template_linux` (2 files) | Linux. Redo is Ctrl+Shift+Z and Close is Ctrl+W here, Ctrl+Y and Ctrl+F4 on Windows |
| `freecad_template_mac` (3 files) | macOS, "FreeCAD" |

App names: the 1.1.4 AppImage, run under Xvfb (X11) on 2026-10-22, reports the
process `freecad` (its `AppRun` is a shell script that starts `usr/bin/freecad`)
and WM_CLASS `freecad` / `FreeCAD`. Its desktop file is `org.freecad.FreeCAD`,
which is also the Flatpak app id. The Windows and macOS names were not checked
on an install.

## Shortcut reference

FreeCAD's source at tag 1.1.4 (4fd3bf3), read 2026-10-22: every `sAccel` in the
C++ command constructors (`src/Gui/Command*.cpp`, `src/Mod/*/Gui/Command*.cpp`)
and every `Accel` in the Python commands. Keys given as a `QKeySequence`
standard key are resolved with Qt 6.8's per-platform table (`qplatformtheme.cpp`),
which the 1.1.4 packages build against; FreeCAD takes the first key Qt lists.
Qt reads "Ctrl" as Cmd on macOS.

Platform differences in the set: Redo (Ctrl+Y on Windows, Ctrl+Shift+Z
elsewhere), Close (Ctrl+F4 on Windows, Ctrl+W elsewhere), Delete (Backspace on
macOS), Help (F1, Cmd+? on macOS), and F2 (rename) and F5 (refresh), which have
no key on macOS.

The workbench is not in the window title, so the host cannot tell workbenches
apart. The set has the global keys and the single keys of Sketcher (D, A, H, V,
C, O, L, I, P, N, T, R, E, S, W), Draft (Shift+S, Shift+Space) and TechDraw
(Shift+H, Shift+V). None of them is a global key, so outside its workbench such
a key does nothing. PartDesign has no default keys.

### Left out

- Two-key sequences, which one keycap cannot show: the view keys (V, F and
  V, 1..7 and others), workbench switching (W, 1..9), and most Sketcher, Draft,
  BIM, Part, FEM and CAM tools (G, L for a line and so on); 237 of the 377 keys.
- Keys that exist only after a user action: Ctrl+1..9 (views saved with Freeze
  Display) and Ctrl+Shift+1..3 (recent macros).
- The macro debugger keys (F6, Shift+F6, F9, F10, F11 step into): F11 is also
  Full Screen, which the set shows.
- Ctrl+Q (Quit). Esc (toggle navigation/edit mode): the ESC key carries the
  program mark, which the host draws.
- The BIM, Assembly, Spreadsheet and Robot keys. BIM's Ctrl+arrows and Ctrl+,
  conflict with the global dock-panel and Preferences keys, which the set shows.
- macOS: Next/Previous window (Cmd+}, which Qt gives with and without Shift).

The FreeCAD wiki gives Std_Refresh as Ctrl+R and Std_Recompute as
Ctrl+Shift+R; the 1.1.4 source has Std_Recompute on Ctrl+R and Std_Refresh on
F5. The set follows the source.

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>. Folder names are in
  `fetch_icons.py`.
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: every `ms:`
  entry in `fetch_icons.py`.
- Text in DejaVu Sans Bold, drawn in `fetch_icons.py`: the view names (FRT, TOP,
  RGT, REAR, BTM, LFT) and the constraint symbols (H/V, |, ↔, ↕, ∥, ⊥, ⌀, =, ⋈).
  The tangent symbol (a circle under a line) is drawn.
- New, Open, Save, Save As, Print, Close, Undo, Redo, Cut, Copy, Paste, Select
  All, Delete, Zoom In and Zoom Out are drawn by the shared concept renderer.
