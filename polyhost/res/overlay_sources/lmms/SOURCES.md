# LMMS overlays — sources

One spec (`bindings.yaml`) writes two sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `lmms_template` (3 files) | Windows and Linux |
| `lmms_template_mac` (4 files) | macOS |

App names: `lmms` (`lmms.exe` on Windows, the Linux binary and AppImage, the
macOS app "LMMS") and the Flatpak app id `io.lmms.LMMS`. Not checked on an
install.

## Shortcut reference

LMMS's own source, read 2026-11-12 at two points:

- the release tag `v1.2.2`, the current stable release:
  `src/gui/MainWindow.cpp`, `src/gui/editors/Editor.cpp`,
  `src/gui/editors/SongEditor.cpp`;
- `master` @ [`f2a4cd24`](https://github.com/LMMS/lmms/tree/f2a4cd24de5ab61c12d706d8d8fed0b731963467),
  the 1.3 development builds: the same files plus
  `src/gui/editors/PianoRoll.cpp`.

| Keys | Where | Versions |
|---|---|---|
| New, Open, Save (QKeySequence::New/Open/Save), Save As (Ctrl+Shift+S), Save as New Version (Ctrl+Alt+S), Export (Ctrl+E), Export Tracks (Ctrl+Shift+E), Export MIDI (Ctrl+M), Quit (Ctrl+Q), Undo, Redo | `MainWindow::finalize()` | both |
| Redo also on Ctrl+Y and Ctrl+Shift+Z on every system | `MainWindow::finalize()` | 1.2.2 |
| Space play/stop | `Editor.cpp` (a `QShortcut` in 1.2.2, `keyPressEvent` in master) | both |
| Shift+Space pause | `Editor::keyPressEvent`, `MainWindow::keyPressEvent` | master |
| Shift+Insert / Shift+Enter insert bar, Shift+Delete / Shift+Backspace remove bar, Left/Right one bar, Home to start | `SongEditor::keyPressEvent` | both |
| Delete / Backspace (selected clips), Ctrl+A (select all clips), Ctrl+0 (reset zoom) | `SongEditor::keyPressEvent` | master |
| Cut, Copy, Paste (Ctrl+X/C/V) | `PianoRoll` edit actions | both |
| F5 Song Editor, F6 Beat+Bassline Editor, F7 Piano Roll, F8 Automation Editor, F9 FX Mixer, F10 Project Notes | `MainWindow::finalize()` | 1.2.2 |
| Ctrl+1..7 Song Editor, Pattern Editor, Piano Roll, Automation Editor, Mixer, Controller Rack, Project Notes; Shift+F11 maximize editor; Ctrl+Shift+D / Ctrl+Alt+Shift+D detach / attach all subwindows | `MainWindow.cpp`, `Editor.cpp` | master |

Qt's `Qt::CTRL` and `ControlModifier` are the Command key on macOS, so every
Ctrl key is `CMDCTRL` in the spec. `QKeySequence::Redo` is Ctrl+Y and
Ctrl+Shift+Z on Windows, Ctrl+Shift+Z on Linux and Cmd+Shift+Z on macOS. The
set draws Ctrl/Cmd+Shift+Z everywhere and Ctrl+Y off macOS; on Linux, Ctrl+Y
works in 1.2.2 only.

The two versions bind the editor windows to different keys, and neither key set
does anything in the other version, so both are drawn.

### Left out

- F11: Controller Rack in 1.2.2, Full screen in master.
- The Piano Roll and Automation Editor tool keys (Shift+D/E/S/T/G/K/J/F/C/R),
  the Pattern Editor's + and -, Esc (deselect; the program mark is drawn there)
  and the file browser's Ctrl+F: they act only in that subwindow, and the host
  sees one window.
- Record, metronome and loop: LMMS binds no key to them.

## Icons

- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: `detach`
  (open_in_new), `attach` (close_fullscreen).
- Byte-identical copies of the icons another DAW set draws for the same
  action (`BORROW` in `fetch_icons.py`), from `../ableton`, `../reaper`,
  `../flstudio`, `../logicpro` and `../garageband`. Their sources and licences
  are in those folders' `SOURCES.md`.
- New, Open, Save, Save as, Quit, Undo, Redo, Cut, Copy, Paste, Delete, Select
  all and Zoom reset are drawn by the shared concept renderer.

**ESC mark.** LMMS is licensed GPL-2.0-or-later: `LICENSE.txt` is the GPL
version 2 text, and the source headers read "either version 2 of the License,
or (at your option) any later version". The icon is in the same tree under the
same licence, and PolyKybdHost is GPL-3.0-or-later, so the real icon is used.
It is a white glyph on a green tile. `dcc_glyphs.trace_mark` lights only the
white glyph (`lit="light"`, luma 210) at 32x32, and the generator places it
1:1 with `program_icon_mode: alpha`, anchored right in a 37x32 region with no
margin. The cut was chosen from a sweep of luma 60..235 in both directions: at
180 and below the green tile's edge survives; 210 and 235 give the glyph alone,
and 210 keeps the thicker strokes.
