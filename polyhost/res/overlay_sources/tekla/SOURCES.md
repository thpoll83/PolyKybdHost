# Tekla Structures overlays — sources

One spec (`bindings.yaml`) writes one set, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `tekla_template` (2 files, 103 keys) | Windows, `TeklaStructures.exe` |

App name: `TeklaStructures.exe` is the Tekla Structures executable; the mapping
also lists `tekla structures`. Neither name was checked on a running install.
Tekla Structures runs only on Windows.

## Shortcut reference

Tekla Structures 2026 user guide, "Default keyboard shortcuts" (modified
20 Jan 2026), fetched 2026-11-06:
<https://support.tekla.com/doc/tekla-structures/2026/gen_keyboard_shortcuts>.

The set has the modeling keys. Drawing mode opens in the same window and
gives several keys another meaning. The host cannot tell the two modes apart:
the drawing editor's window title was not confirmed to show the mode
(Tekla's documentation does not describe the title bar), so no title route is
added.

### Left out

- Drawing mode, because the keys conflict with modeling: Ctrl+O (Document
  manager), Shift+P (print drawings), Ctrl+Page Down / Ctrl+Page Up (next /
  previous drawing), Shift+A (associativity symbol), B (drawing color mode),
  Shift+G (ghost outline), G (orthogonal dimension), F (free dimension),
  U / Shift+U (UCS), Ctrl+T (toggle orientation), Ctrl+1 / Ctrl+0 (reset
  current / all), and the Document manager and Master drawing catalog keys
  (Alt+U, Ctrl+M, Ctrl+R, Ctrl+A, Alt+A, Alt+C).
- Ctrl+F1 (help for an open tooltip): it acts only while a tooltip is shown.
- Ctrl+arrow keys and Shift+arrow keys (rotate with the keyboard): the page
  does not say which key rotates in which direction or around which axis.
- Alt+click, Shift+click, Ctrl+click (select assembly, add to selection,
  toggle selection) and Ctrl+Shift when a drawing is created: mouse actions or
  a modifier alone.
- Esc (interrupt): the ESC key carries the program mark.

The four rendering keys 1 to 4 show the same cube in the Ctrl (parts), Shift
(components), Ctrl+Shift (references) and Ctrl+Alt (building hierarchy)
layers; the modifier held is what tells the object type.
