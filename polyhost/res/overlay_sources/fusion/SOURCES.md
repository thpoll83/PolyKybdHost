# Autodesk Fusion overlays — sources

One spec (`bindings.yaml`) writes two sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `fusion_template` (2 files) | Windows, `Fusion360.exe` |
| `fusion_template_mac` (3 files) | macOS, "Autodesk Fusion" (and "Autodesk Fusion 360" before the 2024 rename) |

App names: the Windows executable is still `Fusion360.exe` after the rename to
Autodesk Fusion (Autodesk forum threads; no Autodesk document names the file).
The macOS app is `Autodesk Fusion.app`, earlier `Autodesk Fusion 360.app`
(a third-party detection script and a forum crash report). None of these names
was checked on a running install. Fusion has no Linux version.

## Shortcut reference

Fusion help, "Fusion keyboard shortcuts reference",
<https://help.autodesk.com/cloudhelp/ENU/Fusion-GetStarted/files/GUID-F0491540-0324-470A-B651-2238D0EFAC30.htm>,
fetched 2026-10-22. It gives the Windows and the Mac key side by side for the
global keys; the Design and Sketch letters have one column, used for both. The
Mac keys that are not the Cmd/Option version: Redo (Cmd+Shift+Z).

Every workspace (Design, Render, Simulation, Manufacture, Drawing,
Electronics, ...) is one window of one process, so the host cannot tell them
apart. The set has the global keys and the Design workspace keys, including the
sketch keys (L, R, C, T, O, P, X, D), which share no letter with the Design keys.

### Left out

- The keys of the other workspaces. Most letters mean something else there: E is
  Extrude in Design, Settings in Generative design and Simulation, Manual Explode
  in Animation and Errors in Electronics.
- macOS: Cycle document tabs (the reference gives Cmd+Tab, the system app
  switcher), Previous/Next workspace and the Autodesk Assistant keys (the
  reference gives no Mac key).
- The Autodesk Assistant zoom keys (Ctrl++ and Ctrl+-), which act only in the
  Assistant panel.
- Mouse actions (pan, orbit, zoom) and holding Shift to snap to a midpoint.
- Esc: the ESC key carries the program mark, which the host draws.

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>. Folder names are in
  `fetch_icons.py`.
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: every `ms:`
  entry in `fetch_icons.py`.
- New, Open, Save, Undo, Redo, Cut, Copy, Paste and Delete are drawn by the
  shared concept renderer.
