# Autodesk Inventor overlays — sources

One spec (`bindings.yaml`) writes one set, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `inventor_template` (2 files, 40 keys) | Windows, `Inventor.exe` |

App name: `Inventor.exe` is the Inventor executable. It was not checked on a
running install. Inventor runs only on Windows.

## Shortcut reference

Inventor 2026 help, "Keyboard Shortcut Reference", fetched 2026-11-06:
<https://help.autodesk.com/cloudhelp/2026/ENU/Inventor-Help/files/GUID-DEEB0723-DFC7-4B28-95F4-099CC1E1EBF8.htm>.
The page says it is a subset of the predefined keys and command aliases.

Every environment (part, sketch, 3D sketch, assembly, drawing, presentation)
runs in one window, so the host cannot tell them apart. Where a key has two
meanings, the part/sketch meaning is drawn:

| Key | Drawn | Not drawn |
|---|---|---|
| F2 | Pan (graphics window) | Rename (model browser) |
| C | Center point circle (sketch) | Constraint (assembly) |
| D | General dimension (sketch, drawing) | Face draft (part) |
| T | Text (sketch, drawing) | Tweak components (presentation) |

Keys with one meaning are drawn in whichever environment they act: M, N and P
(assembly) and B (drawing) have no other meaning.

### Left out

- The multi-letter command aliases, because their first letter has a
  single-key meaning of its own: BDA (Baseline dimension set; B), CH (Chamfer)
  and CP (Circular pattern; C), FC (Feature control frame; F), LE (Leader text)
  and LO (Loft; L), MI (Mirror; M), RO (Rotate component) and RP (Rectangular
  pattern; R), S3 (3D sketch) and SW (Sweep; S), TR (Trim; T). ODS (Ordinate
  dimension set) is the only alias whose letter, O, has no single-key meaning
  on the page; it is not drawn either, because the page is a subset and O may
  have a single-key meaning that it does not list.
- Mouse actions: Alt+drag, Shift+right click, Shift+Rotate.
- Esc (quit command): the ESC key carries the program mark.
