# OpenSCAD overlays — sources

One spec (`bindings.yaml`) writes three sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `openscad_template` (2 files) | Windows, `openscad.exe` |
| `openscad_template_linux` (2 files) | Linux. Find and Replace is Ctrl+Alt+F here, Ctrl+Shift+F on Windows |
| `openscad_template_mac` (3 files) | macOS, "OpenSCAD" |

App names on Linux, measured 2026-10-22 by running 2021.01 (Ubuntu package) and
the 2026.10.18 nightly AppImage under Xvfb (X11):

| Build | Process (`ps -o comm=`) | Executable | WM_CLASS class |
|---|---|---|---|
| 2021.01 package | `openscad` | `openscad` | `OpenSCAD` |
| 2026.10.18 AppImage | `AppRun` | `openscad` | `OpenSCAD` |

The AppImage's `AppRun` is a symlink to `usr/bin/openscad`, and a process is
named after the path it was started from, so `ps` reports `AppRun`. The host
reads the executable name instead (`win_process.app_name_for`). The nightly's
desktop file sets `StartupWMClass=org.openscad.openscad`, and the mapping lists
that name and `openscad-nightly` too. The Windows and macOS names were not
checked on an install.

## Shortcut reference

OpenSCAD's own source, read 2026-10-22 at two refs:

1. tag `openscad-2021.01` (41f58fe5), the last stable release;
2. master 7bbf6038 (2026-10-18), the source of the 2026.10.18 nightly.

The keys are the `shortcut` properties in `MainWindow.ui` and the keys set in
code (`mainwin.cc` in 2021.01, `src/gui/MainWindow.cc` on master, and the editor
in `ScintillaEditor.cpp`). Qt reads "Ctrl" in a `.ui` file as Cmd on macOS; the
editor's autocomplete and call tip keys use the physical Control key there.

Keys only master has, which do nothing on 2021.01: Ctrl+Alt+Up/Down (move line),
Ctrl+J (Jump to), Ctrl+K and Ctrl+H (next and previous window). F7 is Export as
STL in 2021.01 and exports the 3D format set in Preferences on master, STL by
default.

Ctrl+] and Ctrl+[ (zoom in and out) work only while the 3D view has focus: the
editor keeps them as paragraph down and up.

### Left out

- 2021.01 only: F10 (Surfaces) and F11 (Wireframe), removed on master.
- Master only: D (Measure Distance) and A (Measure Angle), which type a letter
  while the editor has focus.
- Ctrl+Q (Quit), the editor's duplicate-line keys (Ctrl+Shift+Up/Down, which on
  macOS are also select to start/end of document), Alt+Left/Right (move to the
  next digit) and the AltGr move-line keys.
- macOS: Cmd+Tab (next tab) and Cmd+H (previous window) are system keys; F3
  (reload) and Alt+Up/Down (change the number at the caret, Option+Shift+keypad
  arrows on a Mac) do not exist there.
- Keys inside dialogs and docks (Discard in the save dialog, Return in the error
  log). Esc: the ESC key carries the program mark, which the host draws.

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>. Folder names are in
  `fetch_icons.py`.
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: every `ms:`
  entry in `fetch_icons.py`.
- Text in DejaVu Sans Bold, drawn in `fetch_icons.py`: the view names (TOP, BTM,
  LFT, RGT, FRT, BCK, CTR), `//` for comment and a struck `//` for uncomment,
  +1 and −1. The next and previous bookmark icons are Material `bookmark` with a
  drawn triangle.
- New, Open, Save, Save As, Close, Undo, Redo, Cut, Copy, Paste, Find, Replace,
  Find Next, Zoom In and Zoom Out are drawn by the shared concept renderer.
