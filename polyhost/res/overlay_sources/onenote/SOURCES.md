# OneNote overlays — sources

One spec (`bindings.yaml`) writes two sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `onenote_template` (3 files) | OneNote on Windows (`onenote`, process `ONENOTE.EXE`) |
| `onenote_template_mac` (4 files) | OneNote on macOS (`microsoft onenote`) |

`ONENOTE.EXE` also hosts the new Sticky Notes. The mapping sends a window titled
"Sticky Notes…" to `stickynotes_template` and every other `onenote` window to
this set.

## Shortcut reference

Microsoft, "Keyboard shortcuts in OneNote",
<https://support.microsoft.com/en-us/office/keyboard-shortcuts-in-onenote-44b8b3f4-c274-4bcc-a089-e80fdcc87950>,
fetched 2026-10-21. The page has four tabs. The Windows set uses the **Windows
desktop** tab (OneNote, formerly OneNote 2016), not the "OneNote for Windows 10"
tab. The macOS set uses the **macOS** tab. The web tab is not used.

### Windows: chords that the page gives in two ways

The Windows desktop tab contradicts itself or the Windows 10 tab in a few places.
Each was resolved as follows:

| Action | Page says | Drawn | Why |
|---|---|---|---|
| Subscript | Ctrl+Shift+Minus | Ctrl+= | The same tab gives Ctrl+Shift+Hyphen to "select paragraph and subordinates". The Windows 10 tab and every other Office app use Ctrl+=. |
| Superscript | Ctrl+Shift+Plus | Ctrl+Shift+= | The same physical keys (Plus is Shift+=). |
| Indent / outdent | Alt+Shift+Right / Left, and the reverse under "Select text" | Right = indent, Left = outdent | The "Format notes" table and the Windows 10 tab agree on this direction. |
| Strikethrough | Alt+Hyphen | Alt+Hyphen | Drawn as documented. The Windows 10 tab says Ctrl+Hyphen. Check on hardware. |

### Left out

- Zoom (Ctrl+Plus / Ctrl+Minus): Ctrl+Plus needs Shift on a US layout, which is
  Ctrl+Shift+= (superscript), and Ctrl+Minus collides with the strikethrough
  question above.
- Ctrl+Shift+W (Information Bar),
  Ctrl+Alt+G / Ctrl+Shift+G (focus moves), Alt+PgUp / Alt+PgDn (same as
  Alt+Home / Alt+End in practice), the arrow and Home/End navigation, and
  keys that only work in a sequence (Alt+N, F; Ctrl+E, Tab, Space).
- Windows key chords (Win+Shift+N, Alt+Win+N, Win+Shift+S): these are global
  and start OneNote or the Snipping Tool from anywhere.
- Esc and Ctrl+Esc: the ESC key carries the program mark.

### macOS

Cmd+B / Cmd+I / Cmd+U are not on the macOS tab; they are the standard macOS text
commands and OneNote for Mac follows them. Everything else in the macOS set is on
the macOS tab. Left out: Ctrl+Shift+Plus / Minus (the page swaps expand and
collapse), Cmd+Ctrl+G / Ctrl+Shift+G (focus moves), and the arrow navigation.

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>. Folder names are in
  `fetch_icons.py`.
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>:
  `content_paste_go` (paste text), `format_list_numbered`, `add_column_right`,
  `add_column_left`, `ink_highlighter` (Highlight tag), `subdirectory_arrow_right`
  (new subpage), `task` (open Outlook task), `date_range` (task this week),
  `next_week` (task next week).
- `level1..9.png`: Fluent `Square` with a digit, from `../number_badge.py`.
- `onenote.png` (ESC): drawn in `fetch_icons.py`, the Office-family mark with an
  "N". No Microsoft artwork.
