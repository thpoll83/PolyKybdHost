# Discord overlay — sources

Generated by `scripts/generate_app_overlays.py` from `bindings.yaml`; icons in
`icons/` are (re)built by `fetch_icons.py` except the reclaimed ones.

## Shortcut references

support.discord.com is blocked by the build session's egress proxy (as were the
mirrors tried), so each chord was confirmed from search-result excerpts of these
pages. A chord no excerpt confirmed was left out.

- "[Windows] Discord Hotkeys" — https://support.discord.com/hc/en-us/articles/225977308--Windows-Discord-Hotkeys
- "[macOS] Discord Hotkeys" — https://support.discord.com/hc/en-us/articles/225878307--macOS-Discord-Hotkeys
- Discord blog, "How to Navigate Discord Using Only Your Keyboard" — https://discord.com/blog/how-to-navigate-discord-using-only-your-keyboard
- Discord blog, "How to Use Keyboard Shortcuts on Discord" — https://discord.com/blog/how-to-use-keyboard-shortcuts-on-discord-create-custom-keybinds
- Cross-checks: keychron.com Discord guide, partitionwizard.com, tutorialtactic.com

The Linux client ships the Windows keymap; it shares the Windows artwork set.

### Deliberate change: the logo moved from TAB to ESC

The old PNG drew the Discord logo on TAB in all four layers — a program mark on
a shortcut key. It is now `program_icon:` on ESC, the house convention. Because
the mark fills the ESC cell on every layer, the old Esc (mark channel read) and
Shift+Esc (mark server read) drawings cannot stay: the generator ORs a binding
into the mark. Their art is kept in `icons/` so it survives if the mark ever moves.

## Fetched icons

Fluent UI System Icons (MIT): Arrow Swap (quick switcher), Mic Off (mute), Call,
Mail Inbox, Arrow Upload, Mention, Speaker 2 (return to voice channel).

`mark_chat_unread` (unread channel).

## macOS

| Action | Windows / Linux | macOS | Spec |
|---|---|---|---|
| Ctrl chords (E, P, U, /, K, I, Shift+U, Shift+M, Shift+D) | Ctrl+… | ⌘+… | CMDCTRL |
| Prev/next server | Ctrl+Alt+↑/↓ | ⌘⌥↑/↓ | CMDCTRL+ALT |
| Unread mentions | Ctrl+Shift+Alt+↑/↓ | ⌘⇧⌥↑/↓ | CMDCTRL+ALT+SHIFT |
| Channels / unread channels | Alt(+Shift)+↑/↓ | ⌥(⇧)↑/↓ | literal ALT |
| Start call | Ctrl+' | not confirmed | `except: [macos]` |
| Return to voice channel | Ctrl+Alt+A | not confirmed | `except: [macos]` |

No binding uses a reserved macOS chord.

## Skipped

- Esc / Shift+Esc — see above.
- Ctrl+Shift+N (create/join server), Ctrl+Shift+T (private group), Ctrl+F
  (search), Ctrl+B (previous text channel), Ctrl+Enter (answer call), Tab (focus
  text area): not confirmed by any excerpt, or not worth a keycap.
