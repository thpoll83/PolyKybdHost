# SketchUp Pro overlays — sources

One spec (`bindings.yaml`) writes two sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `sketchup_template` (1 file, 24 keys) | Windows, `SketchUp.exe` |
| `sketchup_template_mac` (2 files, 23 keys) | macOS, "SketchUp <year>" (the mapping drops the trailing year) or "SketchUp" |

App names: `SketchUp.exe` is the SketchUp executable on Windows, and the macOS
app is named "SketchUp <year>". Neither name was checked on a running install.
SketchUp has no Linux version.

## Shortcut reference

Fetched 2026-11-06:

- SketchUp help, "Default Keyboard Shortcuts" (last updated 21 Oct 2026),
  <https://help.sketchup.com/en/default-keyboard-shortcuts>: 19 single keys and
  3 Shift keys. The page has one table and no Windows/macOS split, so the same
  keys are drawn on both.
- SketchUp help, "Erasing and Undoing",
  <https://help.sketchup.com/en/sketchup/erasing-and-undoing>: "The default
  keyboard shortcut for Undo is Alt+Backspace. However, Ctrl+Z (Microsoft
  Windows) or Command+Z (macOS) also work." Ctrl/Cmd+Z is drawn on both;
  Alt+Backspace only on Windows, because Alt+Backspace is a Windows
  convention and the page does not say it applies on macOS.

### Left out

- Copy, Paste, Cut, Redo, Save and the other edit keys: SketchUp's help does
  not document them.
- The mouse actions in the table (click and drag for Orbit, Shift+click and
  drag for Pan, the scroll wheel for Zoom).
- Esc: the ESC key carries the program mark.
