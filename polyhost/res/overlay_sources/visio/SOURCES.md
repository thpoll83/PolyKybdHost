# Visio overlays — sources

`bindings.yaml` writes `visio_template` (2 files), generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`. It loads
for `visio` (`VISIO.EXE`). Visio has no macOS version, so there is no `_mac` set.

## Shortcut reference

Microsoft, "Keyboard shortcuts for Visio",
<https://support.microsoft.com/en-us/office/keyboard-shortcuts-for-visio-14b36b20-9b98-428b-a7f9-54d03fa6419a>,
fetched 2026-10-21, the Windows desktop tab. The page does not list the standard
Office file and edit commands (Ctrl+N, O, S, P, Z, Y, X, C, V, F). Visio uses them
like every Office app, so they are drawn as label-only bindings through the
shared concept renderer.

### Left out

- Ctrl+Shift+G: the page lists it beside Ctrl+G for Group. One key is drawn.
- Ctrl+Shift+H (replace with field height), Ctrl+F10 and Ctrl+F5 (window size),
  F1 (Help), F6 (pane focus), Shift+F10 (context menu): not worth a keycap or
  standard Windows behaviour.
- Arrow, Home/End and Page Up/Down navigation, and the dialog-box keys.
- Page Down / Page Up in full-screen view: the same keys scroll in normal view.
- Esc: the ESC key carries the program mark.

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>. Folder names are in
  `fetch_icons.py`.
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>:
  `conversion_path` (Connector tool), `line_curve` (Arc tool), `flip_to_front`,
  `flip_to_back`.
- `visio.png` (ESC): drawn in `fetch_icons.py`, the Office-family mark with a
  "V". No Microsoft artwork.
