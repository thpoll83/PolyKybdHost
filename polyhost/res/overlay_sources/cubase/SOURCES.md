# Cubase overlays — sources

One spec (`bindings.yaml`) writes two sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `cubase_template` (2 files) | Windows |
| `cubase_template_mac` (3 files) | macOS |

App names: Cubase names its executable after the major version,
`Cubase14.exe` on Windows and the app "Cubase 14" on macOS. The mapping lists
versions 12 to 15 in both forms. The matcher drops neither form's number (no
dot), so a new major version needs a new name. Not checked on an install;
Cubase Artist and Elements were not checked either. Cubase has no Linux
version.

## Shortcut reference

Cubase Pro 14 Operation Manual, chapter "Key Commands" > "Default Key
Commands", one page per category (Add Track, Audio, Automation, Chords,
Devices, Direct Offline Processing, Edit, Editors, File, Focus, Marker, Media,
MIDI, MixConsole History, Navigate, Nudge, Project, Quantize, Set Insert
Length, Tool, Track Versions, Transport, Window Zones, Workspaces, Zoom).
<https://www.steinberg.help/r/cubase-pro/14.0/en/cubase_nuendo/topics/key_commands/key_commands_default_c.html>,
read 2026-11-12 through the site's own content API
(`/api/khub/maps/9_A2jNxlDJdZgViRgyezjA/topics/<id>/content`), because the
page itself is built by JavaScript and `archive.steinberg.help` answered 403.

The manual writes "Ctrl/Cmd" and "Alt/Opt": the Windows key first, the macOS
key second. Ctrl/Cmd is `CMDCTRL` in the spec and Alt/Opt is `ALT`. Every key
the set draws is the same chord on both systems.

### Left out

- Numeric keypad keys (no cell): Record (Num *), Cycle (Num /), Stop (Num 0),
  Start (Enter), Rewind and Forward (Num - / Num +), the locator keys
  (Num 1, Num 2, Ctrl/Cmd+Num 1/2), Recall Cycle Marker, Go to Project Start,
  Workspaces, and the MediaBay pane keys (Ctrl+Alt/Opt+Num n).
- The MIDI editor keys: Set Insert Length (Alt/Opt+1..8, Alt/Opt+, and .),
  Show/Hide Controller Lanes (Alt/Opt+L).
- Focus (Tab, Shift+Tab, Ctrl/Cmd+Alt/Opt+Return, Alt/Opt+Shift+Space),
  Toggle Selection (Ctrl/Cmd+Space), the Primary/Secondary Parameter keys
  (Ctrl/Cmd+Shift+arrows), the Nudge Start/End/Top/Bottom keys (Alt/Opt+arrows),
  Add Left/Right/Up/Down (Shift+arrows).
- The fields that open a value entry in the Transport panel (Shift+L/R/D/P/I/O/T/C),
  Exchange Time Formats (.), Activate External Sync (Alt/Opt+Shift+T), Auto-Grid
  (Shift+Q), Expand/Reduce (Alt/Opt+E), Invert (Alt/Opt+F), Mute/Unmute Objects
  (Alt/Opt+M), Group Editing (K), Move Event Start to Cursor (Ctrl/Cmd+L),
  Colors (Alt/Opt+Shift+S), Show/Hide Channel (Ctrl/Cmd+Alt/Opt+C), the tab and
  page keys of the zones (Ctrl/Cmd+Alt/Opt+arrows), Track Versions
  (Ctrl/Cmd+Shift+D/N/G/H), Search MediaBay (Shift+F5).
- F2: the chapter's introduction names F2 "Show/Hide Transport panel", and the
  Edit table names it "Rename Selected Events". The set follows the table.
- Esc: the ESC key shows the program mark, which the host draws.

The key commands of the On-Screen Keyboard take priority while it is shown;
the overlay cannot tell.

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>: `unlock` (Lock Open),
  `color` (Color).
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: every `ms:`
  entry in `fetch_icons.py`.
- Byte-identical copies of the icons another DAW set draws for the same
  action (`BORROW` in `fetch_icons.py`), from `../ableton`, `../reaper`,
  `../flstudio`, `../protools` and `../soundcraft`. Their sources and licences
  are in those folders' `SOURCES.md` (Fluent MIT, Material Apache-2.0, and the
  drawn crossfade in `../protools`, GPL-3.0-or-later).
- New, Open, Save, Save as, Close, Quit, Undo, Redo, Cut, Copy, Paste, Select
  all, Delete, Lock, Zoom in and Zoom out are drawn by the shared concept
  renderer.

**ESC mark.** None is baked in. Cubase is proprietary, so the host draws the
mark for the running app (its own OS icon first, then the icon catalogs), as
for Ableton Live, FL Studio and REAPER.
