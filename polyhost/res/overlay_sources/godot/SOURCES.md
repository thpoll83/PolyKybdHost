# Godot editor overlays: sources

Five specs, generated by `scripts/generate_app_overlays.py`; `fetch_icons.py`
rebuilds `icons/`. The PolyKybd Reporter plugin (`godot-plugin/`) reports the
editor's main screen as `godot://<screen>`, and the mapping draws that screen's
set on top of the shared set (a later file takes priority per key).

| Spec | Set | Loads for | Keys (Windows/Linux, macOS) |
|---|---|---|---|
| `godot.yaml` | `godot_template` | every screen; alone for Asset Store, another plugin's screen, and no report | 60, 59 + ESC mark |
| `godot_2d.yaml` | `godot_2d_template` | `godot://2d` | 30, 30 + ESC mark |
| `godot_3d.yaml` | `godot_3d_template` | `godot://3d` | 37, 36 + ESC mark |
| `godot_script.yaml` | `godot_script_template` | `godot://script` | 59, 58 + ESC mark |
| `godot_game.yaml` | `godot_game_template` | `godot://game` (Godot 4.4+) | 2, 2 + ESC mark |

The largest switch (shared set plus Script set) shows fewer than 130 distinct
images, far below the 600 limit.

## Shortcuts

Godot's default bindings, read from the source of Godot **4.7.2-stable** (the
`ED_SHORTCUT*` calls, with their `ED_SHORTCUT_OVERRIDE(..., "macos", ...)`
lines for macOS) and checked against the docs page *Default editor shortcuts*
(<https://docs.godotengine.org/en/4.6/tutorials/editor/default_key_mapping.html>,
the newest version of that page; the 4.7 docs have no such page). Where the
two disagree, the source is used: the docs page is marked outdated.

| File (godotengine/godot at 4.7.2-stable) | Keys |
|---|---|
| `editor/editor_node.cpp` | main screens (Ctrl+F1..F5, macOS Cmd+Ctrl+1..5), scene files, quick open, command palette, quit, help, fullscreen, distraction free, screenshot, Ctrl+J; node lock/group/visibility (2D and 3D sets) |
| `editor/run/editor_run_bar.cpp` | F5, F6, Ctrl+Shift+F5, F7, F8 and their macOS keys |
| `editor/docks/scene_tree_dock.cpp` | add child node, instantiate, duplicate, paste as sibling / replacement, copy node path, move node, rename, batch rename, Shift+Del |
| `editor/debugger/editor_debugger_node.cpp`, `editor/docks/filesystem_dock.cpp` | Alt+D, Alt+F |
| `editor/scene/canvas_item_editor_plugin.cpp` | 2D set |
| `editor/scene/3d/node_3d_editor_plugin.cpp` | 3D set |
| `editor/script/script_text_editor.cpp`, `editor/script/script_editor_plugin.cpp` | Script set |
| `editor/run/game_view_plugin.cpp` | Game set (F9, F10; macOS Cmd+Shift+B) |

From the docs page only (defined in files not read): Undo / Redo, the
Animation, Audio, Output and Shader panels (Alt+N, A, O, S), the debugger's
F10, F11, F12, the 2D zoom keys, and in the Script set Redo (Ctrl+Y), Select
next occurrence (Ctrl+D), Complete symbol (Ctrl+Space) and zoom.

Left out on purpose:

- Keypad keys (3D views, grid step): no keycap cell.
- 3D axis locks (X, Y, Z, Shift+X/Y/Z): only while a transform runs, and Y is
  also Use Snap. Freelook W A S D Q E: only while the right mouse button is
  held. Hold Space (2D pan): no Space layer.
- Keys with no default binding (Project Settings, Export, and so on).
- macOS Cmd+Shift+B is both Toggle Breakpoint and Go to Previous Bookmark in
  Godot; the Script set shows Toggle Breakpoint.
- `Align Transform with View` is Ctrl+Alt+M / Ctrl+Alt+G with a different
  macOS override; only Ctrl+Alt+M is drawn, and not on macOS.

## App names (routing)

From the Godot source and the release file names, not checked on an install:

- Windows: the official download is `Godot_v4.x.y-stable_win64.exe` (also
  `_console`, `_mono_win64`); the host cuts a Windows process name at its first
  dot, so all of them are `godot_v4`. A source build is
  `godot.windows.editor.x86_64.exe`, so `godot`.
- Linux: the download `Godot_v4.x.y-stable_linux.x86_64` is reported by its
  executable name; `common.mapping_key` drops a version followed by a release
  tag and a build (`_VERSION_AND_BUILD`), so it matches `godot`. The X11
  WM_CLASS class of the editor is `Godot`
  (`platform/linuxbsd/x11/display_server_x11.cpp`), which the GNOME and KDE
  reporters return. The Wayland app id is `org.godotengine.Editor` (4.5+,
  `display_server_wayland.cpp`); the Flatpak is `org.godotengine.Godot` and
  runs `godot-bin`. `godot4` is the name some distributions give the 4.x
  package.
- macOS: the app is `Godot.app` ("Godot"); the .NET build is `Godot_mono.app`.
- A project run from the editor is a second process with the same executable,
  so its window matches this entry too. The plugin sends `focused: false` when
  the editor loses focus, so that window gets the shared set, not a screen set.

renderer draws them, the same as in every other set.
