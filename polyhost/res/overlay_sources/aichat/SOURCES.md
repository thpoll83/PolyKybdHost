# AI assistant overlays — sources

Five sets from one icon folder, generated by `scripts/generate_app_overlays.py`.
`fetch_icons.py` rebuilds `icons/`.

| Set | Spec | Loads for |
|---|---|---|
| `claude_desktop_template` | `claude_desktop.yaml` | the Claude desktop app (`claude`) |
| `claude_web_template` | `claude_web.yaml` | `claude.ai` in a browser |
| `claude_code_web_template` | `claude_code_web.yaml` | Claude Code on the web (`claude.ai/code`) |
| `chatgpt_template` | `chatgpt.yaml` | the ChatGPT desktop app (`chatgpt`) and `chatgpt.com` |
| `codex_template` | `codex.yaml` | the Codex desktop app (`codex`) |

Each spec writes a Windows/Linux set and a macOS (`_mac`) set; `CMDCTRL` is Cmd
on macOS and Ctrl elsewhere.

## Shortcut references

### Claude desktop app (Code tab) — official

<https://code.claude.com/docs/en/desktop#keyboard-shortcuts>, fetched as
Markdown (`desktop.md`). All 16 chords of the table are drawn except `Esc`
(stop the response), which sits under the ESC program mark, and `1`–`9`
(select an item in an open menu), which has no single action to draw. The doc
says session cycling, the terminal toggle and the view-mode toggle use Ctrl on
every platform; those are literal `CTRL` in the spec.

The Chat and Code tabs share one window and one process, so this set also
shows while the Chat tab is open.

### Claude desktop app (Chat tab)

Read off the Windows app's own shortcut list by the owner (2026-10-02). Drawn,
all `except: [macos]` because the macOS forms are not confirmed: Ctrl+K quick
chat or search, Ctrl+Shift+K search, Ctrl+Q switch between recents, Ctrl+B
sidebar, Ctrl+, settings, Ctrl+Alt+Right/Left next/previous sidebar tab, Ctrl+U
add files or photos, Ctrl+D dictation, Ctrl+Shift+. model menu, and Ctrl+1..9
jump to chat N. The digit keys show a filled square with the number punched out
(`number_badge.knockout`), since "the Nth chat" has no picture of its own.

The list's Ctrl+/, Ctrl+N, Ctrl+W, Ctrl+Tab, Ctrl+Shift+Tab and Ctrl+Shift+]/[
mean the same in both tabs and were already drawn. Left out: Enter and
Shift+Enter (send, new line), and two chords that mean different things in the
two tabs, Ctrl+Shift+E (Chat: toggle thinking, Code: effort menu) and
Ctrl+Shift+I (Chat: incognito chat, Code: model menu). The set cannot tell the
tabs apart, so the Code tab's meaning stays drawn.

### claude.ai — provisional

Anthropic publishes no shortcut list for claude.ai; the in-app list is behind
Ctrl+/ (Cmd+/). The three drawn chords (Ctrl+/ shortcuts, Ctrl+Shift+O new
chat, Ctrl+K search) were given by several third-party lists and contradicted
by none. Left out because the lists disagree: Ctrl+. and Ctrl+Shift+S (sidebar),
and Ctrl+K as "new chat". Cross-checked lists (search excerpts, the pages
themselves are blocked by the session proxy): fastshortcuts.com/shortcuts/claude,
techguruplus.com/claude-ai-shortcut-keys, mfsinitishk.github.io/claude-mastery-guide,
linuru.com/claude.

### Claude Code on the web

Read off the web interface's own shortcut hints by the owner (2026-10-01), on
Windows/Linux: Ctrl+Alt+M permission mode, Ctrl+B sidebar, Ctrl+Shift+D
changes (diff), Ctrl+Shift+F files. The macOS forms are not confirmed, so all
four are `except: [macos]` and the macOS set carries the ESC mark only.

### ChatGPT

ChatGPT's in-app list (Ctrl+/), as reproduced by shortcutref.com/en/chatgpt,
fastshortcuts.com/shortcuts/chatgpt, coursera.org/articles/chatgpt-keyboard-shortcuts
and tomsguide.com (search excerpts). Drawn: Ctrl+/, Ctrl+Shift+O, Ctrl+K,
Ctrl+Shift+S, Ctrl+Shift+C, Ctrl+Shift+;, Ctrl+Shift+I, Ctrl+Shift+Backspace.
Not drawn: Shift+Esc (focus the message box), under the ESC mark.
Ctrl+Shift+I opens Chrome's DevTools when ChatGPT runs in a tab.

### Codex desktop app

The "Commands" page of the Codex app docs,
<https://developers.openai.com/codex/app/commands>, read through search
excerpts (the host is blocked by the session proxy), cross-checked with
codexhandbook.com/en/guide/reference/keyboard-shortcuts. Toggle diff panel is
confirmed as Cmd+Option+B on macOS only, so it is `only: [macos]`. Codex
chords are user-rebindable; this set draws the defaults.

Codex in a browser (`chatgpt.com/codex`) has no set: the mapping routes it to
the browser overlay so the ChatGPT set does not load there.

Keyboard, Chat Add, Search, Panel Left, Window Console, Settings, Apps List
Detail, Dismiss, Arrow Previous, Arrow Next, Arrow Left, Globe, Cursor Click,

Block, Person Edit, Delete, Folder Open, Document Search, Archive, Document
Multiple, History, Attach, Mic.

Drawn here: `jump1.png`..`jump9.png`, the knocked-out digit squares
(`../number_badge.py`, Liberation Sans Bold, SIL OFL).

## Program marks (ESC)

- `claude.png` — the Claude mark from Simple Icons (`claude.svg`, artwork
  CC0-1.0), rendered by `../brand_marks.py`. Nominative use: it identifies the
  app the set is for.
- `chatgpt.png`, `codex.png` — drawn letter frames (`GPT`, `Cx`) from
  `../rect_mark.py`. OpenAI's mark is in neither Simple Icons nor MDI, and its
  brand terms do not allow redistribution.

The marks are guarded: a committed file is never overwritten by a re-run.
