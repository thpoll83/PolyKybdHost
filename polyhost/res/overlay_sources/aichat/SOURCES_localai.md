# Local-model chat apps (LM Studio, Jan): sources

Two more sets in the AI assistant folder, generated by
`scripts/generate_app_overlays.py`. `fetch_icons.py` builds the shared icons
(`newchat`, `search`, `sidebar`, `settings`, `model`); `fetch_icons_localai.py`
builds the ones only these two sets use and their program marks. Run both.
This file is kept apart from `SOURCES.md` only so it could be added without
editing that file; fold it in when convenient.

| Set | Spec | Loads for |
|---|---|---|
| `lmstudio_template` | `lmstudio.yaml` | LM Studio (`lm studio`, `lm-studio`) |
| `jan_template` | `jan.yaml` | Jan (`jan`, `jan-desktop`) |

Both write a Windows/Linux set and a macOS (`_mac`) set; `CMDCTRL` is Cmd on
macOS and Ctrl elsewhere.

## Shortcut references

### LM Studio

LM Studio's own docs (fetched 2026-10-13; also in <https://lmstudio.ai/llms.txt>).
Each chord is documented as Cmd on macOS and Ctrl on Windows/Linux.

| Chord | Action | Page |
|---|---|---|
| Ctrl+N | New chat | <https://lmstudio.ai/docs/app/basics/chat> |
| Ctrl+Shift+N | New chat folder | <https://lmstudio.ai/docs/app/basics/chat> |
| Ctrl+L | Open the model loader | <https://lmstudio.ai/docs/app/basics> (image caption) |
| Ctrl+2 | Discover tab | <https://lmstudio.ai/docs/app/basics/download-model> |
| Ctrl+3 | My Models tab | <https://lmstudio.ai/docs/app/advanced/prompt-template> |
| Ctrl+Shift+R | LM Runtimes | <https://lmstudio.ai/docs/app> |
| Ctrl+, | Settings | <https://lmstudio.ai/docs/app/user-interface/languages> |

Not drawn: Ctrl+K then T (theme selector, a two-key sequence; Ctrl+K alone is
not documented), other tab digits (undocumented), standard editing chords
(not documented by LM Studio).

### Jan

The app's own code, `janhq/jan` at `3d9529df281e4d5d2784cdbae75979bf05929013`
(Apache-2.0):

- `web-app/src/lib/shortcuts/const.ts`: the table. Every entry is
  `usePlatformMetaKey: true`, i.e. Cmd on macOS, Ctrl elsewhere
  (`lib/shortcuts/platform.ts`, `hooks/useHotkeys.ts`).
- `web-app/src/providers/KeyboardShortcuts.tsx`: which entries have a live
  handler. Ctrl+N new chat, Ctrl+B sidebar, Ctrl+P new project, Ctrl+, settings,
  Ctrl+K search, Ctrl+J switch assistant.
- `web-app/src/hooks/useMessageZoom.ts`: Ctrl+= / Ctrl+- zoom the chat text.
- The Projects doc, <https://jan.ai/docs/desktop/projects>, confirms ⌘P.

Not drawn: Ctrl+M (new agent chat): it is in `const.ts`, but its handler is
commented out. The `jan` agent CLI's keybindings
(`docs/src/pages/docs/agent/keybindings.mdx`) belong to a terminal program, not
to the desktop app.

## Icons

Microsoft Fluent UI System Icons (MIT): Folder Add (`newfolder`), Library
(`mymodels`), Developer Board (`runtimes`), Person Swap (`assistant`).
Google Material Symbols (Apache-2.0): `explore` (`discover`). Fluent's Compass
Northwest was tried first and its needle read as a leaf at 1 bit.
Reused from `fetch_icons.py`: `newchat`, `search`, `sidebar`, `settings`, `model`.
Zoom in / Zoom out / Settings are drawn by the shared concept renderer.

## Program marks (ESC)

- `jan.png`: Jan's own app icon, `src-tauri/icons/icon.png` at the commit above,
  Apache-2.0 (GPLv3-compatible). A waving hand. Swept alpha / luma / bright at
  t150..225 and 37x32 / 40x38; `luma` t225 at 37x32 keeps the fingers apart and
  the motion lines lit.
- `lmstudio.png`: a drawn generic mark (`_lmstudio_mark` in
  `fetch_icons_localai.py`): a rounded box with five bars offset along one period
  of a vertical sine wave, 368 lit px, legend lost 0 px. LM Studio is closed
  source and is in neither Simple Icons nor MDI. The maintainer picked it
  (2026-10-14) over the `LM` letter frame first drawn here.

Both marks are guarded: a committed file is never overwritten by a re-run.
