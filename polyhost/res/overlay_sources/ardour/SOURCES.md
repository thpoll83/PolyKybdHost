# Ardour overlays — sources

One spec (`bindings.yaml`) writes two sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `ardour_template` (2 files) | Windows and Linux |
| `ardour_template_mac` (3 files) | macOS |

App names: on Linux the bundle's launcher is `ardour<major>` (`ardour8`) and the
binary it starts is `ardour-<version>` (for example `ardour-8.12.0`), which the
matcher's trailing-version rule turns into `ardour`; the Flatpak app id is
`org.ardour.Ardour`. On Windows and macOS the app is "Ardour" or
"Ardour<major>". The mapping lists `ardour`, `ardour7`, `ardour8`, `ardour9` and
the Flatpak id. Not checked on an install.

## Shortcut reference

Ardour's own default bindings, `gtk2_ardour/ardour.keys.in` at
[`Ardour/ardour@35f6a410`](https://github.com/Ardour/ardour/blob/35f6a410ce9e6deac3e06983f29deef12757e527/gtk2_ardour/ardour.keys.in)
(read 2026-11-12). The file calls itself "the reference for any bindings or
cheatsheets"; `tools/fmt-bindings` turns it into the shipped bindings. It names
modifiers by role, and `fmt-bindings` maps them per system:

| role | Windows / Linux | macOS | spec |
|---|---|---|---|
| PRIMARY | Ctrl | Cmd | `CMDCTRL` |
| SECONDARY | Alt | Ctrl | `ALT` with `except: [macos]` and `CTRL` with `only: [macos]` |
| TERTIARY | Shift | Shift | `SHIFT` |

PRIMARY+SECONDARY is written out per system (Ctrl+Alt, and Cmd+Ctrl on macOS),
because `CMDCTRL` and `CTRL` cannot be combined in one binding. The comment
after each binding names the Ardour action. The bindings were selected by hand
from the file; the selection is reproducible from the action names.

The set has the Editor and global keys. Some keys mean something else while
MIDI notes are selected (the `notes` group: comma, period, arrows, c, v, j, s,
q, Tab and others); the overlay shows the Editor meaning.

### Left out

- The MIDI note-editing keys (group `notes`) and the Recorder page keys (group
  `rec`).
- The numeric keypad (no cell), the mouse bindings, Esc (the program mark).
- F1..F12 and Ctrl/Cmd+F1..F12 (go to and save visual state 1..12).
- Keys whose action has no clear picture or acts only in a dialog: the
  selection keys (select all after/within/between, in loop or punch range,
  visible lanes), `toggle-midi-input-active`, `show-editor-props`,
  `ToggleSummary`, `ToggleVerticalSummary`, `show-rhythm-ferret`,
  `toggle-rtawindow`, `ToggleMaximalMixer`, the monitor section keys, the
  MIDI patchbay, the playlist keys (Shift+; and Shift+'), the layer display
  keys (Shift+[ and Shift+]), Record with pre-roll / count-in (Shift+, and
  Shift+.), Toggle Auto Play, Toggle Follow Edits, Toggle External Sync, set
  tempo from edit range (0), Page Up/Down, the tab keys, plain Up/Down
  (scroll), Shift+Up/Down (transition to roll), the region boundary and
  region sync keys, trim to previous/next region, `fork-regions`,
  `select-from-regions`, `add-range-marker-from-selection`,
  `align-regions-start-relative`, `align-regions-sync-relative`.
- Two lines of the file are malformed (`<@PRIMARY>` without its closing `@`:
  copy and new playlists for armed or all tracks) and are not drawn.

## Icons

- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: every `ms:`
  entry in `fetch_icons.py`.
- Byte-identical copies of the icons another DAW set draws for the same
  action (`BORROW` in `fetch_icons.py`), from `../ableton`, `../reaper`,
  `../soundcraft`, `../protools` (the drawn fades, GPL-3.0-or-later),
  `../flstudio`, `../cubase` and `../logicpro`. Their sources and licences are
  in those folders' `SOURCES.md`.
- New, Open, Save, Quit, Undo, Redo, Cut, Copy, Paste, Select all, Delete,
  Zoom in and Zoom out are drawn by the shared concept renderer.

**ESC mark.** Ardour is licensed "GPL v2.0 or later" (the "Plugin Clarification" in its
`COPYING`; the source headers read "either version 2 of the
License, or (at your option) any later version"). The logo SVG is in the same
tree under the same licence, and PolyKybdHost is GPL-3.0-or-later, so the real
logo is used. The SVG is a flat one-colour triangle whose bottom edge is a
waveform. It is rendered at 8x the keycap size, reduced to 37x32 with LANCZOS
and cut at alpha 160 (`fetch_icons.py::_mark`), then placed 1:1 with
`program_icon_mode: alpha`, anchored right in a 37x32 region with no margin.
The cut was chosen from a sweep of widths 37/42/46 and alpha 100/160/220: at
37 px and 160 the waveform's vertical strokes stay separate. "Ardour" is a
trademark of its author, used here only to name the app on its own key.
