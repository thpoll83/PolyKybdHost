# Chrome / Chromium overlay — sources

Generated by `scripts/generate_app_overlays.py` from `bindings.yaml`. The
reclaimed artwork and every pre-existing binding come from the previously shipped
hand-drawn set (see the header of `bindings.yaml`).

## Standard editing shortcuts (shared Fluent concepts, 2026-10-08)

Label = lexicon concept, no icon (the shared Fluent concept renderer draws it).
This set sits UNDER every web-app overlay (GitHub, Jira, ...), so these chords
also cover editing on web pages.

| Concept | Windows / Linux | macOS | Source |
|---|---|---|---|
| Save | Ctrl+S | ⌘S | `IDC_SAVE_PAGE` in accelerator_table.cc / accelerators_cocoa.mm; Chrome help "Open options to save the current page" |
| Open | Ctrl+O | ⌘O | `IDC_OPEN_FILE`; Chrome help "Open a file from your computer" |
| Print | Ctrl+P | ⌘P | `IDC_PRINT`; Chrome help "Open options to print the current page" |
| Cut / Copy / Paste | Ctrl+X/C/V | ⌘X/C/V | Win/Linux: `GetStandardAcceleratorForCommandId` in accelerator_table.cc + Blink editing_behavior.cc; macOS: `IDC_CUT/COPY/PASTE` in accelerators_cocoa.mm |
| Undo | Ctrl+Z | ⌘Z | Blink editing_behavior.cc (`'Z', kCtrlKey, "Undo"`, non-Mac); macOS `IDC_CONTENT_CONTEXT_UNDO` ⌘Z |
| Redo | Ctrl+Y and Ctrl+Shift+Z | ⌘⇧Z | Blink editing_behavior.cc (`'Y', kCtrlKey` and `'Z', kCtrlKey\|kShiftKey` → "Redo", non-Mac); macOS `IDC_CONTENT_CONTEXT_REDO` ⌘⇧Z |
| Select all | Ctrl+A | ⌘A | Blink editing_behavior.cc (`'A', kCtrlKey, "SelectAll"`); macOS `IDC_CONTENT_CONTEXT_SELECTALL` ⌘A |

Not added / why:
- Find (Ctrl/⌘F), Find next (Ctrl/⌘G, F3), Close (Ctrl/⌘W, Ctrl+F4), Reload
  (Ctrl/⌘R, F5), Zoom in/out (Ctrl/⌘ =/-): already bound above with reclaimed art.
- New: Ctrl/⌘N is already "New window" above.
- ⌘Y on macOS: it is History (`IDC_SHOW_HISTORY`, already drawn), so macOS
  Redo is ⌘⇧Z only. Ctrl+Y Redo is scoped `only: [windows, linux]`.
- Replace: Chromium has no find-and-replace chord.
- Paste and match style (Ctrl+Shift+V / ⌥⇧⌘V): not a lexicon concept.
