# MuseScore Studio overlays — sources

One spec (`bindings.yaml`) writes three sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `musescore_template` (2 files) | Windows, `MuseScore4.exe` |
| `musescore_template_linux` (2 files) | Linux, `mscore` / `musescore`; Redo is Ctrl+Shift+Z here |
| `musescore_template_mac` (3 files) | macOS, "MuseScore Studio" / "MuseScore 4" |

App names, from the v4.7.5 build files: `src/app/CMakeLists.txt`
(`EXECUTABLE_NAME`), `version.cmake` (`MUSE_APP_NAME`, `MUSE_APP_TITLE`, bundle
id `org.musescore.MuseScore`), `buildscripts/ci/macos/package.sh` (bundle folder
"MuseScore 4.app"), `src/app/main.cpp` (desktop file name
`org.musescore.MuseScore`). Which of "MuseScore Studio" (CFBundleName) and
"MuseScore 4" (folder) macOS reports was not checked, so both are mapped.

## Shortcut reference

MuseScore Studio 4.7.5 (tag `v4.7.5`), read 2026-10-21:

- `src/app/configs/data/shortcuts.xml`, the defaults on Windows and Linux;
- `src/app/configs/data/shortcuts_mac.xml`, the defaults on macOS
  (`src/framework/shortcuts/internal/shortcutsconfiguration.cpp` picks it under
  `Q_OS_MACOS`);
- the action titles and contexts in the `*uiactions.cpp` files.

Compared with 4.6.5, the keys are the same; 4.7 renamed some action codes and
added Alt+W (Extend to Next Note) and Shift+Space (Play from Selection).

The Mac file uses Qt's notation: "Ctrl" is Cmd, "Meta" is Control, "Alt" is
Option. It differs from the Windows file in six keys: Paste Half/Double Duration
(Control+Shift+Q/W), Insert Measure (Shift+I), Insert Measures (Option+Shift+I),
Pause and Select (Option+Space) and Full Screen (Control+Cmd+F as well as F11).
Undo, Redo, Open, Save and Close are Qt standard keys; Redo expands to Ctrl+Y on
Windows and Ctrl+Shift+Z on Linux and macOS.

### Context

MuseScore keys depend on the context (`src/context/shortcutcontext.h`): the
score, text editing, note input on a tablature staff. The set draws the meaning
in the score view:

- letters A–G enter notes, Shift adds the note to the chord, Ctrl+Shift inserts
  it;
- digits 1–9 pick a duration (1 = 64th … 7 = whole, 8 = double whole,
  9 = longa), 0 is a rest;
- Ctrl+B adds a measure (Bold while editing text), Ctrl+I toggles insert mode
  (Italic while editing text), Enter adds a system break, Space plays.

### Left out

- Keys with two meanings in the score: Shift+Left/Right (extend selection, or
  move the chord), Alt+Up/Down (next note in chord, or move measure to the next
  system), Ctrl+1–9 used to advance the chord-symbol cursor (they are drawn as
  tuplets, their score meaning).
- Tablature note-input keys (frets on 0–9 and A–K, durations on Shift+digits,
  `;` rest) and the text-editing keys (Ctrl+B/I/U, Space, arrows, `-`).
- UI navigation keys (Tab, F6, arrows, Home/End, PgUp/PgDn without Ctrl),
  developer keys (Ctrl+F1–F3), F5 (OMR, no action found), Ctrl+Q (Quit),
  Ctrl+Alt+0 and Ctrl+Alt+- (voice assignment), Shift+L (accessibility),
  Shift+F2 and the context-menu keys.
- H as a second key for B (German note name).
- Esc: the ESC key carries the program mark, which the host draws.

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>. Folder names are in
  `fetch_icons.py`.
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: every `ms:`
  entry in `fetch_icons.py`.
- Note names, durations, accidentals (♯ ♮ ♭), intervals, voices and tuplets are
  text in DejaVu Sans Bold, drawn in `fetch_icons.py`.
- New, Open, Save, Save As, Print, Undo, Redo, Cut, Copy, Paste, Delete, Select
  All and Find are drawn by the shared concept renderer.
