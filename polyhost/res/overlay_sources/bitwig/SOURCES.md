# Bitwig Studio overlays — sources

One spec (`bindings.yaml`) writes two sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `bitwig_template` (2 files) | Windows and Linux |
| `bitwig_template_mac` (3 files) | macOS |

App names: "Bitwig Studio" (`Bitwig Studio.exe` on Windows, the macOS app),
`BitwigStudio` and `bitwig-studio` (the Linux binary and launcher), and the
Flatpak app id `com.bitwig.BitwigStudio`. Not checked on an install.

## Shortcut reference

Bitwig Studio User Guide, version 5.2 (July 2024),
<https://downloads.bitwig.com/documentation/Bitwig%20Studio%20User%20Guide%20English.pdf>,
read 2026-11-12. Bitwig publishes no key list: the guide gives each key in the
text where the function is described, and the in-app list is Dashboard >
Settings > Shortcuts. Section 0.3 says a key that is the same on every system is
written once, and otherwise the Windows/Linux key comes first and the Mac key
second, "[CTRL]+[C] ([CMD]+[C] on Mac)". The set draws:

| Keys | Guide section |
|---|---|
| Group, Remove group | 3.2.2 |
| Cut, Copy, Paste, Duplicate, Delete (tracks) | 3.2.3 |
| Select all | 10.2.1 ("[CTRL]+[A] ([CMD]+[A] on Mac)") |
| Split (Ctrl+E), Fade in/out to here (Shift+7 / Shift+0), Set object start/end (Shift+8 / Shift+9) | 5.2.2 (Time menu functions; the same list in 10.2 and 11.2) |
| Consolidate (Ctrl+J) | 5.1.3 |
| Switch object/time selection (Ctrl+T, one key on every system) | 5.2, 9.3, 10.2, 11.2 |
| Play/stop (Space, P), from playhead (Shift+Space, Shift+P), from start (Alt+Space, Alt+P) | 5.5 |
| Tools 1..5 (Pointer, Time selection, Pen, Eraser, Knife) | 3.1.4 |
| Beat grid: , and . (smaller/larger), / (adaptive) | 3.1.2 |
| Alt+, / Alt+. (subdivision), S (Toggle Snap, "default mapping") | 16.2.1.1 |
| Panels I, E, A, D, M and their Alt versions; Alt+B (Browser) | 2.2.1 |
| B (Browser) | 14.4.1 |
| Arrows: previous/next clip and track, move by grid; Ctrl+Up/Down first/last track | 5.2.1, 5.2.2 |
| - and Ctrl+- (zoom out) | 3.1.1 |

The file and a few edit keys are not in the guide. They are taken from two
third-party lists, both read 2026-11-12, and drawn only where the guide's
CTRL/CMD convention gives the Mac key:

- New (Ctrl+N), Open (Ctrl+O): RouteNote, "50 keyboard shortcuts for faster
  workflow in Bitwig Studio", <https://create.routenote.com/blog/50-keyboard-shortcuts-for-faster-workflow-in-bitwig-studio/>,
  and TutorialTactic, "Bitwig Studio Keyboard Shortcuts",
  <https://tutorialtactic.com/blog/bitwig-studio-shortcuts/> (Windows only).
- Save (Ctrl+S), Save as (Ctrl+Shift+S), Undo (Ctrl+Z), Quantize (Q),
  Settings (Ctrl+,), Loop selection (Ctrl+L), Bounce in place (Ctrl+B):
  TutorialTactic; Quantize, Settings, Loop and Bounce in place also in muted.io,
  "Bitwig Keyboard Shortcuts" (Bitwig 3.3), <https://www.muted.io/bitwig-keyboard-shortcuts/>.

### Left out

- Redo: TutorialTactic gives Ctrl+Y for Windows only, and the Mac key is not
  documented.
- Record, metronome and arranger loop: no default key is documented in the
  guide or in either list.
- Alt+A: the guide gives it for the Automation Editor panel (2.2.1) and for
  Activate/Deactivate Track (3.2.6). The plain A is drawn.
- [PLUS] and Ctrl+[PLUS] (zoom in): on a US layout + is Shift+=, and the guide
  does not say which key Bitwig reads.
- muted.io's track keys (Ctrl+T instrument track, Ctrl+Shift+T audio track):
  in 5.2 Ctrl+T switches object/time selection, so that list is out of date
  there.
- Keys that act only in one editor or browser (note transpose, gain, browser
  filters and sources F1..F9, Ctrl+0), Caps Lock (computer note keyboard),
  Esc (the program mark, which the host draws).

## Icons

- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: `seltoggle`
  (swap_horiz), `subdivless` (grid_3x3), `subdivmore` (grid_4x4).
- Byte-identical copies of the icons another DAW set draws for the same
  action (`BORROW` in `fetch_icons.py`), from `../ableton`, `../reaper`,
  `../flstudio`, `../protools` (the drawn fades, GPL-3.0-or-later),
  `../soundcraft`, `../cubase` and `../logicpro`. Their sources and licences are
  in those folders' `SOURCES.md`.
- New, Open, Save, Save as, Undo, Cut, Copy, Paste, Select all, Delete and Zoom
  out are drawn by the shared concept renderer.

**ESC mark.** None is baked in. Bitwig Studio is proprietary, so the host
draws the mark for the running app (its own OS icon first, then the icon
catalogs; Simple Icons has `bitwig`).
