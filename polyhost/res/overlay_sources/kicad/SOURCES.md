# KiCad overlays — sources

Two specs write two sets each, generated by `scripts/generate_app_overlays.py`;
`fetch_icons.py` rebuilds `icons/`. They replace the hand-drawn
`kicad_pcb_template.png`, which had 14 icons and no sources.

| Spec | Set | Loads for |
|---|---|---|
| `pcb.yaml` | `kicad_pcb_template` (2 files), `_mac` (3 files) | a window title ending in "PCB Editor" |
| `schematic.yaml` | `kicad_sch_template` (2 files), `_mac` (3 files) | a window title ending in "Schematic Editor" |

Process names: `kicad` when an editor is opened from the project manager,
`pcbnew` or `eeschema` when it is started on its own. The project manager, the
Symbol Editor and the Footprint Editor get no set.

## Shortcut reference

The default hotkeys of KiCad 10.0.7, read from the `.DefaultHotkey(...)` calls in
the source, fetched 2026-10-21:

- `common/tool/common_tool_actions.cpp` (both editors)
- `pcbnew/tools/pcb_actions.cpp`
- `eeschema/tools/sch_actions.cpp`

Raw URL pattern: `https://gitlab.com/kicad/code/kicad/-/raw/10.0.7/<path>`.
The "Actions reference" tables of the KiCad 10 manuals
(<https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html>,
<https://docs.kicad.org/10.0/en/eeschema/eeschema.html>) list the same keys. The
manual shows the Windows/Linux key only.

`MD_CTRL` is Ctrl on Windows/Linux and Cmd on macOS, so it is drawn as `CMDCTRL`.
The source sets these keys differently on macOS (`#ifdef __WXMAC__` or
`__WXOSX_MAC__`):

| Action | Windows/Linux | macOS |
|---|---|---|
| Redo | Ctrl+Y | Cmd+Shift+Z |
| Delete | Del | Backspace |
| Refresh | F5 | Cmd+R |
| Zoom to fit | Home | Cmd+0 |
| Zoom in / out | F1 / F2 | Cmd++ / Cmd+- |
| Create corner (PCB), repeat last item (schematic) | Insert | F1 |
| Draw zones (PCB) | Ctrl+Shift+Z | Option+Z |

Shifted punctuation is drawn on the US key that types it: `+` (next layer) on
Shift+=, `{` `}` (layer opacity) on Shift+[ and Shift+], `~` (clear net
highlighting) on Shift+`. KiCad matches the typed character, so on another
layout these keys move.

### Left out

- Keys that act only inside a running tool: the router (Backspace undo segment,
  Ctrl+E route from other end, F attempt finish, `/` posture, V and Ctrl+V vias,
  Q custom size, the Ctrl+W track corner modes, Ctrl++ / Ctrl+- next/previous
  layer), the length tuner (1–4), the drawing tools (Backspace delete last point,
  `/` arc posture, Ctrl++ / Ctrl+- line width), Tab skip, Ctrl+Space arc editing
  mode, and the schematic wire tool (Backspace, `/`, C unfold from bus).
- Footprint Editor and Symbol Editor keys: Ctrl+N new footprint, Ctrl+Shift+N
  footprint anchor, P draw pins, Ctrl+L focus the library tree.
- Simulator keys (R run, Shift+P probe, Shift+T tune, its Ctrl+N/O/S): the
  simulator is its own window.
- 3D viewer keys: its own window.
- Ctrl+Shift+A and Ctrl+Shift+C in the PCB Editor. Both are bound twice
  (Unselect All / Draw Arcs, Copy as Text / Draw Circles) and KiCad runs the
  first enabled global action, so which one runs is not known. In the schematic
  they are not drawn either, to keep the two sets the same.
- Ctrl+< (router settings): on a US layout `<` is Shift+, and KiCad falls back
  to Ctrl+, (Preferences) when the shifted key has no binding.
- macOS: Cmd++ zoom in (on a US layout it needs Shift and does not match), Cmd+M
  move individually (the system Minimize) and Cmd+H hierarchy navigator (the
  system Hide).
- Cursor and pan keys (arrows, Ctrl+arrows, Shift+arrows), Return/End click,
  Ctrl+W close, Ctrl+Q quit.
- Esc: the ESC key carries the program mark, which the host draws.

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>. Folder names are in
  `fetch_icons.py`.
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: every `ms:`
  entry in `fetch_icons.py`.
- `fastgrid1.png`, `fastgrid2.png`: Fluent `Square` with a digit, from
  `../number_badge.py`.
- KiCad's own toolbar icons are not used (CC-BY-SA 4.0).
- New, Open, Save, Undo and the other standard commands are drawn by the shared
  concept renderer.
