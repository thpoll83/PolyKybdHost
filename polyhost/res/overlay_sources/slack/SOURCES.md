# Slack overlay — sources

Generated by `scripts/generate_app_overlays.py` from `bindings.yaml`; icons in
`icons/` are (re)built by `fetch_icons.py` except the reclaimed ones.

## Shortcut references

The official page could not be fetched from the build session (the egress proxy
blocks slack.com and every mirror tried), so each chord was confirmed from
search-result excerpts of these pages. A chord no excerpt confirmed was left out.

- Slack Help, "Slack keyboard shortcuts" — https://slack.com/help/articles/201374536-Slack-keyboard-shortcuts
- Slack Help, "Navigate Slack with your keyboard" (F6 / Shift+F6 sections) — https://slack.com/help/articles/115003340723-Navigate-Slack-with-your-keyboard
- Slack Help, "Search in Slack" (Ctrl+F / Ctrl+G) — https://slack.com/help/articles/202528808-Search-in-Slack
- Slack Help, "Create or paste code snippets" (Ctrl+Shift+Enter) — https://slack.com/help/articles/204145658-Create-or-paste-code-snippets-in-Slack
- Cross-checks: howtogeek.com/670384, idownloadblog.com (Mac column), m.io cheat sheet, thena.ai, shortcut-tools.com

## Reclaimed (hand-drawn, previously shipped)

Cut pixel-for-pixel from the old `slack_template.{mods,combo.mods}.png`; they
render 1:1 (`region: [72, 40]`, `anchor: center`), so the Windows/Linux cells are
unchanged.

| Icon | Old cell | Binding now |
|---|---|---|
| `slack.png` | ESC, every layer | `program_icon` |
| `searchconversation.png` | Ctrl+F | CMDCTRL+F |
| `search.png` | Ctrl+G | CMDCTRL+G |
| `nextsection.png` | F6 | F6 (all platforms) |
| `home.png` / `dms.png` / `activity.png` / `later.png` / `more.png` | Ctrl+Shift+1/2/3/4/0 | same, `except: [macos]` |

`dms.png`, `activity.png` and `later.png` are also reused for the documented
Ctrl+Shift+K (DMs), Ctrl+Shift+M (mentions & reactions) and Ctrl+Shift+S (saved /
Later) chords, which open the same views.

## Fetched icons

Microsoft Fluent UI System Icons (MIT, https://github.com/microsoft/fluentui-system-icons)
unless noted: Arrow Swap (quick switcher), Compose, Comment Multiple (threads),
Panel Left, Panel Right, Arrow Upload, Code Block (snippet), Emoji (status),
Headphones (huddle), Text Bold, Text Italic, Text Strikethrough, Code, Settings,
Keyboard, Number Symbol (channel), Arrow Left, Arrow Right.
Google Material Symbols (Apache-2.0, https://github.com/google/material-design-icons):
`mark_chat_unread` (all unreads / unread navigation).
`Bold` and `Italic` are drawn by the shared concept renderer (byte-identical to
every other app's Bold/Italic).

## macOS

Slack's Mac column is the Windows/Linux column with ⌘ for Ctrl, so those lines
are `CMDCTRL`. Exceptions:

| Action | Windows / Linux | macOS | Spec |
|---|---|---|---|
| Prev/next channel | Alt+↑/↓ | ⌥↑/↓ | literal ALT |
| Prev/next unread | Alt+Shift+↑/↓ | ⌥⇧↑/↓ | literal ALT+SHIFT |
| History back/forward | Alt+←/→ | ⌘[ / ⌘] | two lines, disjoint `only:` |
| Home/DMs/Activity/Later/More views | Ctrl+Shift+1/2/3/4/0 | not confirmed | `except: [macos]` |

Reserved-chord check: huddle is ⌘⇧H, not the system ⌘H (Hide). No binding uses
⌘M, ⌘Q, ⌘Tab, ⌘Space, ⌃Space or ⌃arrows.

## Skipped

- **Esc** (mark conversation read) and **Shift+Esc** (mark all read): real chords,
  but the program mark owns the ESC cell on every layer and the generator would
  OR the two drawings together.
- Ctrl+Shift+L (channel browser), Ctrl+Shift+E (people): no excerpt confirmed them.
- Ctrl+Shift+Space (huddle mute): Space has no overlay cell.
- The Ctrl+Shift+digit view keys are kept from the old art but were NOT found in
  Slack's published table; verify them against the in-app list (Ctrl+/).
