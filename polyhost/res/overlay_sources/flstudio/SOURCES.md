# FL Studio overlays — sources

One spec (`bindings.yaml`) writes two sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `flstudio_template` (2 files) | Windows, `FL64.exe` |
| `flstudio_template_mac` (3 files) | macOS, "FL Studio 2024" / "FL Studio 2025" (the bundle is named after the year; its executable is `OsxFL`) |

FL Studio has no Linux version. Only `FL Studio 2025.app` and `FL64.exe` are
confirmed (Image-Line manual, toolbar page; a forum crash report); the 2024 name
and `osxfl` follow the same pattern and are not checked on an install.

## Shortcut reference

Image-Line, "Keyboard & Mouse Shortcuts",
<https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/basics_shortcuts.htm>,
fetched 2026-10-21. It writes each key as Windows/macOS ("Ctrl/Cmd+S") and maps
Ctrl to Cmd and Alt to Option.

FL Studio's Playlist, Piano roll, Channel Rack and Mixer are windows inside one
OS window, so the host cannot tell which one has focus. The set has:

- the keys the manual lists as global: file, export, undo, transport, recording
  and the window keys (F1..F12, Tab, Enter);
- the tool and edit keys the Playlist and the Piano roll share (P, B, D, T, C,
  E, Z, Y tools; select, copy, duplicate, group, mute, zoom).

The manual says "Single key shortcuts will only work when 'Typing keyboard to
piano' (Ctrl/Cmd+T) is OFF." The manual does not list which keys that mode
takes or whether it is on in a new install.

### Left out

- Keys of one FL window only: the Channel Rack (1..0 mute, Ctrl+1..0 solo, Alt+C,
  Alt+Z and others), the Mixer (S solo, Alt+R render and others), the Piano roll
  only keys (F, G, H, J, K, M, O, S and its Alt+letter tools), and the Playlist
  only keys (S slip edit, 5..9, Ctrl+P performance mode, Ctrl+T time marker).
- Numpad keys (pattern select 1..9, +, -, NumPad 0, *, /): the keyboard has no
  numpad.
- Alt+0..9 (open recent file), F3 (tool selector), Ctrl+P (recording precount,
  which is Performance mode in the Playlist).
- macOS: Cmd+Space (Spotlight), Cmd+H (Hide), Cmd+M (Minimize) and Ctrl+Insert
  (fn+Return on a Mac keyboard). The manual does not say which takes priority.
- Esc: the ESC key carries the program mark, which the host draws.

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>. Folder names are in
  `fetch_icons.py`.
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: every `ms:`
  entry in `fetch_icons.py`.
- Open, Save, Save As, Undo, Select All, Copy, Cut, Paste and Delete are drawn by
  the shared concept renderer.
