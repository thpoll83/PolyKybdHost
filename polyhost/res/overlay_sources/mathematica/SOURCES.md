# Mathematica / Wolfram overlays — sources

One spec (`bindings.yaml`) writes three sets, generated by
`scripts/generate_app_overlays.py`; `fetch_icons.py` rebuilds `icons/`.

| Set | Loads for |
|---|---|
| `mathematica_template` (2 files) | Windows |
| `mathematica_template_linux` (2 files) | Linux. Close is Ctrl+W here, Ctrl+F4 on Windows |
| `mathematica_template_mac` (3 files) | macOS |

App names: Mathematica was renamed Wolfram in 14.1. Up to 14.0 the notebook
front end is `Mathematica.exe` (Windows), Mathematica.app (macOS) and
`Mathematica` (Linux). Since 14.1 it is `WolframNB.exe`, Wolfram.app and
`WolframNB` (Wolfram, "Launching Wolfram",
<https://reference.wolfram.com/language/tutorial/LaunchingWolfram.html>). The
mapping lists `mathematica`, `wolframnb` and `wolfram`. None of these names was
checked on a running install.

## Shortcut reference

Fetched 2026-10-21:

1. Wolfram, "Keyboard Shortcut Listing",
   <https://reference.wolfram.com/language/tutorial/KeyboardShortcutListing.html>.
   The Windows keys of the current version. It gives no macOS keys.
2. The menu item reference pages linked from it
   (`https://reference.wolfram.com/language/ref/menuitem/<Item>.html`). 27 of
   them show the key for Windows, Macintosh and Linux, as images. These are the
   macOS keys used where they exist.
3. Wolfram's shortcut card, <http://media.wolfram.com/brochures/mathematicashortcuts.pdf>,
   with Windows, Macintosh and X columns. It is from an older version (its
   styles are Title, Subtitle, Subsubtitle, ...), so it is used only for macOS
   keys that 1. and 2. do not give: the styles (Cmd+1..9), font size (Cmd+= and
   Cmd+-), Bold and Italic, Find, Use Selection for Find, Find Next (Cmd+G),
   Evaluate in Subsession (Option+Shift+Return), Find Selected Function
   (Shift+Cmd+F) and the typesetting keys, which stay Control on the Mac.

The macOS keymap is not a Ctrl to Cmd swap. From 2.: Abort Evaluation is Cmd+.,
Check Spelling Cmd+;, Un/Comment Cmd+/, Clear Shift+Cmd+X, Iconize Selection
Cmd+Ctrl+', Evaluate in Place Cmd+Return, Full Screen Cmd+Option+F, and Add Row
(Ctrl+Return), Add Column (Ctrl+,) and Extend Selection (Ctrl+.) stay Control.

Shifted keys are drawn on the US key that types them: Ctrl+{ and Ctrl+} (open
and close all subgroups) on Ctrl+Shift+[ and Ctrl+Shift+], Ctrl+^ (superscript)
on Ctrl+6, Ctrl+_ (subscript) on Ctrl+-, as on the card.

### Left out

- macOS, no source gives the key: Copy As Plain Text, Inline Free-form Input,
  Hyperlink, New Canvas, Convert To/From Canvas, Clear Formatting, Underline,
  Raw InputForm, Remove from Evaluation Queue, Find Previous (the card's Cmd+D is
  from the old version) and the notebook navigation keys. The Windows and Linux
  sets have them.
- Below (the listing gives Shift+Ctrl+, and the card Ctrl+=, which is now Inline
  Free-form Input), Start/End Inline Cell (the listing gives Ctrl+( and Ctrl+),
  the card Ctrl+9 and Ctrl+0), the matching bracket keys (Alt+], Alt+}, Alt+)).
- Nudge (Alt+arrows) and Documentation Center back/forward (Alt+Left/Right):
  the listing gives Alt+Left and Alt+Right to both.
- The debugger keys (F5, F9, F10, F11, Shift+F11, Shift+Ctrl+F, Ctrl+Break):
  they act only while the debugger runs.
- The graphics drawing keys (O, P, F, L, S, A, G, C, Q, M, T): only while a
  graphic is selected.
- Esc input aliases (Esc a Esc for α and so on): typed sequences, not keys.
- Ctrl+F6 (next notebook window), Exit, PageUp/PageDown, the selection keys
  (Shift+arrows) and Preferences (no key on Windows; on macOS it is in the app
  menu, and the card gives Cmd+, to Interrupt Evaluation).

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>. Folder names are in
  `fetch_icons.py`.
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: every `ms:`
  entry in `fetch_icons.py`.
- `radical.png` (√x) and `fraction.png` (x/y): text in DejaVu Sans Bold, drawn
  in `fetch_icons.py`.
- `delnext.png`: Material `backspace`, mirrored.
- New, Open, Save, Print, Undo, Cut, Copy, Paste, Select All, Find and Find Next
  are drawn by the shared concept renderer.
- ESC: no mark is shipped; the host draws one from the app.
