# Thunderbird overlays — sources

Two specs, generated by `scripts/generate_app_overlays.py`; `fetch_icons.py`
rebuilds `icons/`, and `gen_titles.py` writes the mapping entry.

| Spec | Set | Loads for |
|---|---|---|
| `main.yaml` | `thunderbird_template` (2 files), `_linux` (2 files), `_mac` (3 files) | the main window and every window that is not a compose window |
| `compose.yaml` | `thunderbird_compose_template` (2 files), `_linux` (2 files), `_mac` (3 files) | the compose window |

The compose window runs in the same process as the main window, so only its
title tells it apart: "Write: <subject> - Thunderbird" in English
(`windowTitleWrite` in 153 ESR, `compose-window-title` in 159). `gen_titles.py
--fetch esr153` reads that prefix from every locale in Thunderbird's
`all-locales` list (thunderbird/thunderbird-l10n, main branch) into
`compose_titles.yaml`: 61 of 67 locales translate it, and the other six (af,
ast, ga-IE, mk, pa-IN, uz) show the English prefix. Then `gen_titles.py` writes
the mapping entry between its BEGIN and END markers, and
`tests/res/thunderbird_titles_test.py` checks the two agree.

App names:

- Linux, measured 2026-10-22 by running the Mozilla 158.0.1 tarball under Xvfb
  (X11): process `thunderbird-bin`, WM_CLASS class `thunderbird` (instance
  `Mail` for the main window).
- From the source and build configuration (not run): ESR builds use the class
  `thunderbird-esr`, beta `thunderbird-beta`, nightly `thunderbird-nightly`;
  Mozilla's Flatpak is `org.mozilla.thunderbird` (ESR
  `org.mozilla.thunderbird_esr`); a distribution package's binary is
  `thunderbird`.
- Snap: `thunderbird_thunderbird`, by analogy with the Firefox snap; not checked.
- Windows `thunderbird.exe` on every channel; macOS "Thunderbird",
  "Thunderbird Beta", "Thunderbird Daily". Not checked on an install.

## Shortcut reference

The Thunderbird source, read 2026-10-22: thunderbird/thunderbird-desktop branch
`esr153` (327896a1, 153.5.2esr), mirroring hg comm-esr153, with the Gecko
files (text keys, tab switching, window class) from hg mozilla-esr153. The keys
are the `<key>` elements of `mainKeySet.inc.xhtml` and `messengercompose.xhtml`
with their key letters from the DTD and FTL files; `accel` is Ctrl on
Windows/Linux and Cmd on macOS. The 159 release branch has the same keys.
Mozilla's support article could not be fetched to cross-check.

The three platforms differ more than usual, and the sets follow the source:

| Action | Windows | Linux | macOS |
|---|---|---|---|
| Redo | Ctrl+Y | Ctrl+Shift+Z | Cmd+Shift+Z |
| Tab 1..9 | Ctrl+1..9 | Alt+1..9 | Cmd+1..9 |
| Spaces (Mail, Address Book, Calendar, Tasks, Chat) | Alt+1..5 | Ctrl+1..5 | Control+1..5 |
| New message | Ctrl+N, Ctrl+M | Ctrl+N, Ctrl+M | Cmd+N, Cmd+Shift+M |
| Get messages | F5 | F5, F9 | F5, Cmd+Y |
| Move to folder again | Ctrl+Shift+M | Ctrl+Shift+M | Cmd+Option+M |
| Delete | Delete | Delete | Backspace |
| Help | F1 | F1 | Cmd+? |

The single keys of the main window (A archive, J junk, M read, S star, N/P next
and previous unread, digits for tags, ...) work only while the message list or
the message pane has focus; a text field takes the key first.

### Left out

- Ctrl+Shift+Q (Quit on Windows; Ctrl+Q / Cmd+Q elsewhere), the developer
  tools (Ctrl+Shift+J, Ctrl+Shift+I), F6 and Ctrl+F6 (cycle pane focus), F7
  (caret browsing in the main window), Space and Enter in the message list.
- macOS window keys (Cmd+M, Cmd+H, Cmd+Option+H, Cmd+,).
- Compose: the attachment move keys (Alt+arrows, Alt+Home/End, which act only in
  the attachment pane), Cmd+Space on macOS (Spotlight) and Ctrl+H (Find and
  Replace has no macOS key).
- The calendar dialogs, the address book (its keys repeat the main window's)
  and the chat tab's conversation keys.
- Esc: the ESC key carries the program mark, which the host draws.

## Icons

- Microsoft Fluent UI System Icons, MIT,
  <https://github.com/microsoft/fluentui-system-icons>. Folder names are in
  `fetch_icons.py`.
- Material Symbols, Apache-2.0, <https://fonts.google.com/icons>: every `ms:`
  entry in `fetch_icons.py`.
- `tab1..tab9.png`: Fluent `Tab` with a digit, and `tag1..tag9.png`: Fluent
  `Tag` with a digit, both from `../number_badge.py`.
- Undo, Redo, Cut, Copy, Paste, Select All, Print, Close, Delete, Find, Replace,
  Find Next, Bold, Italic, Underline, Zoom In and Zoom Out are drawn by the
  shared concept renderer.
