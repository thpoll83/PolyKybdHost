# Office on the web overlays — sources

Four specs share one icon folder, generated by `scripts/generate_app_overlays.py`;
`fetch_icons.py` rebuilds `icons/`.

| Set | Spec | Platforms |
|---|---|---|
| `word_web_template` | `word_web.yaml` | Windows, Linux |
| `excel_web_template` | `excel_web.yaml` | Windows, Linux |
| `powerpoint_web_template` (+ `_mac`) | `powerpoint_web.yaml` | Windows, Linux, macOS |
| `onenote_web_template` | `onenote_web.yaml` | Windows, Linux |

Microsoft documents Word, Excel and OneNote for the web with Ctrl chords only and
gives no Mac column, so those three have no macOS set: on a Mac the browser's
keycaps stay. PowerPoint's web table has a Mac column.

## How a tab is recognised

The sets load through the browser entry's `urls-contains` in
`overlay-mapping.poly.yaml`, so they need the browser extension. Two URL forms
are matched, each gated to Microsoft's document hosts (`sharepoint.com`,
`onedrive.live.com`, `officeapps.live.com`, `cloud.microsoft`, `onenote.com`):

- SharePoint and OneDrive for Business share links carry the app in the path:
  `/:w:/` Word, `/:x:/` Excel, `/:p:/` PowerPoint, `/:o:/` OneNote.
- Document URLs carry the file type: `file=Report.docx` on SharePoint,
  `Shared%20Documents/Report.docx?web=1` for a direct file link, and
  `ithint=file,docx` (written `file%2cdocx`) on personal OneDrive. The needles
  are `docx`, `xlsx`, `pptx`, and `onenote` for notebooks. The file-type gates
  need `.docx` or `%2cdocx` at the end of a query value, so a SharePoint site
  named "docx-guides" holding a workbook still gets the Excel set. The
  `onenote` gate needs `ithint=onenote` (personal OneDrive) or the onenote.com
  host, so a SharePoint site named "onenote-team" keeps the browser's keycaps.

There is no title fallback. Office web tab titles are the file name
("Report.docx"), and title matching works on whole words.

### Left out

- Access-key sequences (Alt+Period or Alt+Win, then a letter): one keycap cannot
  show a sequence.
- Arrow, Home/End and Tab navigation, and the comment-thread arrow keys.
- Ctrl+F6 (landmark regions) and Shift+F10 (context menu).
- Excel: Ctrl+PgUp/PgDn to switch sheets. The page notes it does not work in
  Chrome, which keeps it for its own tabs; Ctrl+Alt+PgUp/PgDn is drawn instead.
  Also the Copilot pane chords and the screen-reader "read row/column" chords.
- Excel: Ctrl+O (open) and Ctrl+W (close workbook). The page lists them, but by
  default the browser handles both, and Chrome never lets a page take Ctrl+W.
- OneNote: Ctrl+PgUp/PgDn (page through the notebook), for the same reason as
  Excel's sheet keys.
- PowerPoint: the Slide Show keys (N, P, G, J), which act only in the show.
