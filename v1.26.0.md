# v1.26.0 Tutorials on the keyboard
The protocol moves to 35. Host 1.26.0 still works with firmware 1.13.6, but the tutorial text on the status displays and the darkened keys need firmware 1.13.7. Update both to get the full tutorials.

## 1.26.0: Tutorials on the keyboard 🎓
- **Help & About → Tutorials… opens step-by-step guides**, sorted by category with a short description each. Two ship today: *The MIDI layer* and *Display brightness*.
- **Each step rings the keys to press and shows its text on the status displays.** With firmware 1.13.7 the other keys go dark, and a step can wait for a key press or a layer.
- **Write your own:** a tutorial is one YAML file in the tutorials folder. `polyctl tutorial list|start|next|back|stop` drives them from a terminal.
- **The layout editor rings the key you just changed**, so you can find it on the board.

## 1.25.15 to 1.25.20: Keys that follow the view inside an app 🎛️
A small plugin in each app reports which view has the focus, and the keycaps switch to that view's keys.
- **Ableton Live:** Session View and Arrangement View. Install the script, restart Live and choose PolyKybd as a Control Surface.
- **Houdini:** Scene View and Network Editor. **IDA:** disassembly, graph, pseudocode and hex views. **Binary Ninja:** linear, graph and hex views.
- **DaVinci Resolve:** one set per page, from Media to Deliver. **QGIS:** pan, select, measure and digitize tools.

## 1.25.14: StarCraft II and Generals follow your hotkeys
The StarCraft II and C&C Generals icons move to the keys you rebound in the game.

## 1.25.13: PowerShell installer fix
`irm … | iex` no longer leaves your PowerShell window with changed error settings, variables or `PATH`.
