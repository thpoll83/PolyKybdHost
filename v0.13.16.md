# v0.13.16 Keycap legend size 🔠

⚠️ **Update the keyboard firmware to PolyKybd-fw-v0.15.14 at the same time.** This
release moves the HID protocol to **v13**, and the connect gate is an exact match.

## 0.13.16 — Correct layer names in the layout editor
- The editor's layer labels are regenerated from the firmware's real layer list. They
  had drifted silently: the generator pointed at a path that stopped existing two
  refactors ago, so the tail of the list was mislabelled.
- **Eight** remappable layers now, not nine — the firmware merged its two function
  layers into one.

## 0.13.14 — Keycap legend size 🔠
Pick how large the keyboard draws its main legends, from the tray or the command line.
- Tray → **Keycap Size** → Small / Medium / Large, or `polyctl glyph-size medium`.
- Sends **HID cmd 34**; the bigger faces ride the `latinbig` font-pack bundle, flashed
  automatically on connect.
- **Protocol v13** — pair with firmware PolyKybd-fw-v0.15.14.

## 0.13.8 — `polyctl logs paths` reported real logs as "0 KB"
A sizing bug made every log file look empty — unhelpful precisely when you are
collecting them for a bug report.

## 0.13.6 — VS Code overlays, completed
- The shipped VS Code overlay set gains its missing **macOS** bindings, with every
  existing binding and icon preserved.
- `crash_log.txt` is now bounded, so a crash loop can't grow it without limit.

Plus maintenance releases 0.13.7–0.13.15 🧹 (CI, docs and tooling).
