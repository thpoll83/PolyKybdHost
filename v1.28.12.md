# v1.28.12 Counting keyboards
The protocol moves to 37. Host 1.28.12 works with firmware 1.13.11 and with older firmware. Publish and install the host first. With an older host, firmware 1.13.11 works, but the usage report sends no keyboard ID.

## 1.28.12: Counting keyboards 🔢
- **The usage report counts keyboards, not only computers.** With firmware 1.13.11 or later, PolyKybdHost reads the unique ID of the flash chip in each keyboard half and sends a hash of each one. The raw IDs never leave your computer.
- The hashes are the same on every computer, so one keyboard used on two computers counts once. If you replace one half, one hash changes.
- The report has no name, but the hashes do not change: someone who knows who owns a keyboard and can read the reports can link those reports to that owner.
- `polyctl hwid` shows the IDs of your keyboard and the hashes that are sent. `polyctl telemetry disable` turns the report off.

## 1.28.10 and 1.28.11: Shortcut settings explained
Settings → Keycap icons: the two settings that read shortcuts from app menus now say first what they do and which apps they apply to.
