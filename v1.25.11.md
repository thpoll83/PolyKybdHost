# v1.25.11 Overlays for open-source games

The protocol stays at 34, so this app and the keyboard firmware can be updated in either order.

## 1.25.11: More terminal game commands
`nethack-console` and `cataclysm-launcher` now start the NetHack and Cataclysm overlays. A command with a folder path before it still does not match.

## 1.24.4 and 1.25.1 to 1.25.10: Overlays for open-source games 🕹️
Each set labels the keys of one game with an icon and its shortcut. Needs PolyKybdHost 1.25.10 for the full list.
- **Strategy and management:** Beyond All Reason, KeeperFX, Widelands, Wesnoth, VCMI, Unciv, FreeOrion, FreeCol, Simutrans, OpenLoco, Julius, Augustus, CorsixTH, Endless Sky, Naev, Oolite.
- **Shooters:** GZDoom, UZDoom, Chocolate Doom, Crispy Doom, DSDA-Doom, Woof, the Quake ports, Xonotic, Unvanquished, Red Eclipse.
- **Emulators:** ScummVM, Dolphin, PPSSPP, PCSX2, DuckStation, OpenGOAL, Ship of Harkinian and the Super Mario 64 ports.
- **Sandbox, racing and rhythm:** Luanti, Mindustry, Veloren, OpenMW, OpenXcom, SuperTuxKart, Hedgewars, FlightGear, Thrive, osu!, StepMania, Etterna.
- ⚠️ **Dungeon Crawl Stone Soup, NetHack and Cataclysm: DDA run in a terminal.** The app finds them from the terminal title. Turn on the shell title setting in Integrations → Terminals for bash, zsh and PowerShell.

## 1.25.0: One Integrations dialog 🧩
- **One place for everything the app installs into other programs.** Integrations… (above Settings) has pages for AI agents, Terminals, Editors and Browser, each with its own Install and Remove.
- **AI agents now show a status and can be removed.** Each row says whether the hooks are set up, and the app asks before it changes the config file.

## 1.24.3: C&C Generals, and icons that follow your hotkeys 🎮
- **C&C Generals:** a new overlay for the game.
- **OpenRA:** the Red Alert, Tiberian Dawn and Dune 2000 icons move to the keys you rebound in OpenRA's `settings.yaml`.
- **UT2004:** W, A, S and D show move and strafe arrows.

## 1.24.2: Install without git or Python 📦
`install-app.ps1` and `install-app.sh` download the latest release, a private Python 3.13 and the requirements, then start the app. They add nothing to PATH or the Windows registry. The git-based installers stay for developers.

## 1.24.1: Windows installer fix
`install.ps1` no longer needs a C compiler on Python 3.15.
