# v1.7.0 Faster switches between recent apps

**Protocol 20 → 21.** Update this app first, then the keyboard to firmware **1.3.1**. With older firmware everything keeps working, and app switches send the same reports as before.

## 1.7.0: Faster switches between recent apps ⚡
- **Switching back to an app you used recently now takes about half the reports.** Clearing the old icons and showing the new ones now travel inside the mapping reports (cmd 33) instead of in reports of their own. Over all 60 templates, 249 reports drop to 129.
- **A first switch into an app still clears the old icons before the new ones load.**

## 1.6.3: Remote sessions and shared templates 🖥️
- **NoMachine's connection window no longer counts as a remote session.** The keyboard used to wait for a forwarder that was never there.
- **Chrome, Slack and Outlook send their overlays once per switch**, not twice 200–400 ms apart.
- **A window that has nothing to show clears the keycaps**, instead of leaving the previous app's icons on.
