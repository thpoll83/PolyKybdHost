# v0.9.48 — Column-native font packs

## 0.9.48 — Column-native font packs 🔤
Ships the ABI-2 font packs that match firmware 0.9.82's new column-native glyph format;
the host re-flashes the updated bundles automatically when a keyboard connects.
- ⚠️ Pair with firmware 0.9.82+ — the font-pack format changed, so until both sides are
  updated a keyboard ignores the mismatched pack and shows only its built-in fonts.

## 0.9.46 — Cleaner tray menu ✨
Consolidated the tray-menu icons to one consistent glyph per action, matched to the
existing optical-size-48 icon set.
