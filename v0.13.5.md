# v0.13.5 Report a Problem & sharper app overlays

## 0.13.3 — Crashes end up in the report 🧾
- A crash log is collected alongside the ordinary logs, and the bug report says
  how many crashes it found — so a report about "it just disappeared" carries the
  evidence for it.

## 0.12.2 — The keyboard follows your browser 🌐
- In forwarder mode the focused **browser URL** is relayed to the keyboard
  machine, so a web app gets its own overlays instead of the browser's.
- `tools/poly_console.py` now works on Windows — useful for watching the keyboard
  during a firmware flash, when the app's own console reader is suspended.

## 0.12.1 – 0.12.6 — Report a Problem 🐞
- A guided bug report in the tray: it gathers the logs, the environment it needs
  to actually diagnose the thing, and hands you the result.
- The tray icon waits for the system tray to exist before giving up — the cause
  of "it starts but there is no icon" on a slow login.
- Crashes that previously left no trace at all are now recorded.
- The forwarder endpoint is masked in the report, and a failed step keeps the
  report rather than discarding it.

## 0.11.26 — One-click log collection 📋
- A support bundle from the tray, straight to the clipboard, or via
  `polyctl logs` — no hunting for the log directory.
- The forwarder follows a changed `--host-file` target over the RPC path instead
  of staying pointed at the old machine.

## 0.11.24 — Font-pack flashing that admits failure 📦
- A bundle whose flash failed no longer marks itself as done, and one the other
  keyboard half never confirmed stays queued for a re-flash. Previously a partly
  applied bundle looked finished and was never retried.

## 0.11.21 — CMDCTRL, one shortcut for both worlds ⌘
- Shortcut overlays can use the OS-relative command modifier, so a binding is
  written once and shows Cmd on macOS and Ctrl elsewhere.

## 0.11.11 – 0.11.12 — More apps, better marks 🖼️
- Overlay sets for 14 more apps: video editors, the LibreOffice modules, Sublime
  (including its macOS bindings), notes apps and the web apps.
- Program marks drawn from their real geometry rather than approximated:
  LibreOffice, the Adobe apps, Notion, Confluence, Resolve, Obsidian and Sublime.
- A firmware-update cache entry from before signature support is no longer
  revalidated against a rule it predates.

Plus maintenance releases 0.11.13–0.11.25, 0.12.0, 0.12.3–0.12.5, 0.13.0–0.13.2,
0.13.4 and 0.13.5 🧹 — overlay matching fixes, a shutdown deadlock fix, test and
CI work, and docs.

Requires **protocol 12** firmware, unchanged since v0.11.10.
