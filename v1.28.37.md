# v1.28.37 Forwarder finds the keyboard computer
The protocol stays at 38. This host works with firmware PolyKybd-fw-v1.13.34 and newer, and the two can be updated in either order.

## 1.28.31: Forwarder finds the keyboard computer 🔎
- **Settings → Connections → Forwarders → "Find the keyboard computer from the connection"**: on a computer you reach through NoMachine or Remote Desktop, the forwarder reports to the computer connected on port 4000 or 3389. You no longer need `--host` or a host file.
- ⚠️ **It is used only over the paired connection (or `--report-rpc`)**, so window titles never go to a computer that has connected but not signed in.

## 1.28.32: Lighter connection lookup
The forwarder reads the connection table directly instead of running `ss`, `netstat` or PowerShell. It looks only while the computer is in use and stops after 10 minutes without a window change.

## 1.28.33: Digits after a macro delay
A macro that waits and then types a digit ("wait 5 ms, type 3") now types the digit. Before, the keyboard read it as a 53 ms delay and typed nothing.

## 1.28.35: Fixes found by fuzzing
- **A damaged file in a StarCraft archive** now costs only its own key's icon, not the whole game-art overlay.
- **A user tutorial with an impossible date or a numeric field name** shows in the list as an error, and the other tutorials still load.
- **A window report from the network that has `Infinity` in a shortcut** skips that shortcut instead of failing the whole report.

## 1.28.36: Tutorial waits
A tutorial step with a `seconds` wait of NaN, infinity or a number too large for a float is refused when the script loads. Before, that step never ended.
