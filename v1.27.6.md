# v1.27.6 Agent pages and IDE modes
The protocol moves to 36. Host 1.27.6 still works with firmware 1.13.8 and older, but the page number on Esc and the AI-key ripple for other pages need firmware 1.13.9. Update both to get them.

## 1.27.6: Agent pages 🤖
- **Esc shows "Next 1/2"** in AI mode, so you see which page of agents is shown and how many there are.
- **The AI key ripples when an agent on another page waits or finishes**, so nothing on a hidden page goes unnoticed.
- **Paging is faster:** the host sends each agent's card once and reuses it.
- **Leaving AI mode goes back to page 1.**

## 1.27.0, 1.27.4, 1.27.5: Keys that follow the view in JetBrains, Unity and Godot 🧩
- **JetBrains IDEs:** the keys follow the editor, the Project view, the terminal and the paused debugger. Install the plugin from Integrations → Editors → JetBrains IDEs.
- **Unity Editor:** new sets for the Scene view, Animation, Timeline and Play mode. Add the package with Unity's Package Manager.
- **Godot 4.2+:** new sets for the 2D, 3D, Script and Game screens. Copy the add-on into the project's `addons/` folder.

## 1.27.1, 1.27.2: Six more tutorials 🎓
- **New:** accents, RGB lighting, emoji search, keyboard language, base layouts and record a macro.
- **A step that enters a layer uses a key that stays on it**, and the tutorial goes back one step when you leave the layer.

## 1.26.2, 1.27.3: More game overlays 🎮
- **New:** Team Fortress 2, Apex Legends, Rocket League, Path of Exile 1 and 2, Overwatch 2 and Genshin Impact. In TF2, Apex and Path of Exile the icons follow your own key bindings.
- **C&C Remastered** now uses the game's own default keys: 37 more keys, and "select all on the map" moves to Shift+A.

## 1.26.1: A lone agent is on key 1
A single remaining agent now moves to key 1, not key 0. Gaps between agents close when agents are removed.
