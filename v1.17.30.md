# v1.17.30 Fast link for firmware and font-pack updates
**Protocol stays at 23.** This app and firmware 1.9.6 can be updated independently. The fast link needs firmware 1.9.4 or newer; with older firmware every transfer goes over HID as before.

## 1.17.28 – 1.17.30: Updates over the fast link ⚡
- **Firmware updates stream over the keyboard's new USB serial port** when the firmware has it (1.9.4 or newer): about 11 s for the image instead of about 50 s over HID. If the link stops, the update continues over HID from where it was.
- **Font packs, the icon library, game data and the engine pack use the same link.** A forced reflash of all nine bundles takes 33 s instead of 63 s.
- **The tray tooltip shows the measured link rate**, for example "0.6 MB/s link". A keyboard without the link shows the violet HID mark.
- **After a firmware update, the dialog waits for the flashed keyboard to come back** and ignores other keyboards on the computer.
- **Developer setting "Force HID Link"** sends every transfer over HID, for testing.
- ⚠️ **Linux:** the udev rule needs its new serial-port lines. The tray shows **Updates → Allow access to the keyboard (udev rule)…** while the installed rule is missing or older than the shipped file, and installs it after a PolicyKit password prompt. The one-line installer does the same. Without the lines the app uses HID. ⚠️ **Windows:** if no COM port appears on a computer that had the keyboard before, remove the device in Device Manager and plug it in again.

## 1.17.24: macOS follows the active app again 🍎
- **On macOS the keycaps change with the active app again.** A window query took about 2 s and the switch timer counted it as 250 ms, so a switch could take 15 s or more. The timer now counts real time, and the query is skipped while the same app stays in front.
- **App entries without a window title now work**, such as VS Code's macOS overlays.
- **The background service shows no Dock icon any more.**

## 1.17.23: Outlook on the web 📧
- **The Outlook web overlay has 45 keys on Windows and Linux and 27 on macOS** (read and unread, flag, delete, send, modules, calendar views, People), with Fluent icons.

## 1.17.26 – 1.17.27: Keycap previews and wording
The layout editor's shipped keycap previews were nine firmware versions old: ja-JP showed kana instead of romaji, and ja-US was missing. They now match firmware 1.9.3. The macro editor says "key combinations" instead of "chords".
