# v1.22.4 AI agent keys

The protocol moves to 32. Publish order: update this app first, then the keyboard firmware to 1.13.0. The agent keys and the MIDI layer need firmware 1.13.0; with older firmware the app works as before and leaves those features off.

## 1.22.2: MIDI layer in the layout editor 🎹
- **Key previews for the MIDI layer** of firmware 1.13.0: each key shows the note it plays, and the layer tabs keep their right names after the new layer was added.

## 1.22.0: AI agent keys 🤖
Each AI coding agent session (Claude Code, Codex, Gemini CLI, Copilot CLI, OpenCode, Qwen Code) gets a key on the number row. Its light shows whether the agent is working, waiting for you, done or idle.
- **Hold the AI key** to see one card per agent, then press a number key to bring that agent's window to the front. Holding the number key of a waiting agent does the same.
- **AI Agents → Set Up Hooks** writes the hooks into each agent's settings. Your own hooks are kept, and a backup is saved.
- **Agents on another computer:** pair a forwarder with a code (**AI Agents → Pair a Forwarder…**) instead of copying the key file. A key press brings the remote-desktop viewer forward.
- Off by default: turn it on with **AI Agents → Show on the Number Row**.

## 1.22.3: AI key in the keymap editor
